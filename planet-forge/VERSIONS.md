# Кузня планет: версії даних і сумісність

## v2 (переробка меню й логіки)
- Збереження в браузері: ключ `pf_state3` (параметри планети) без змін; додалися `pf_sys1` (система: зоря, планети, вибрана планета, режим), `pf_panel`, `pf_tab`. Застарілий `pf_sky1` (одноразовий вигляд «літаючий континент») більше не читається.
- Старт тепер із зоряної системи; вигляд планети відкривається кліком по планеті або зі списку.
- Тип `floating` («Літаючі острови») сховано (`hidden`): збережені планети цього типу відкриваються, але в списку й рандомі його немає. Замість нього типи групи `sky`: `skyland` (Літаючий материк), `skyarch` (Небесний архіпелаг): це планети з `shape: 'slab'`, що малюються плитою в космосі.
- Нові параметри літаючих континентів: `span` (розмір найбільшої плити, 2 500…90 000 км), `isl`, `size`, `elev`, `rivers`, `bridges`, `pal`, `pop` (населення 1 млрд…50 трлн), `tiers` (яруси міст), `glow`, `atmo` (щит), `lights`.
- JSON: планета `{ tool, params, passport }`; система `{ tool, system: { seed, star, planets: [{ au, phase, params }] } }`. Імпорт `{ sky }` з попередньої версії перетворюється на `skyarch`.
- Прибрано режим «справжні відстані/розміри» (не працював); орбіти лише скорочені, поле `scale` у збереженні ігнорується.
