# Аудіо редактор і конвертер

Відкриваєш аудіо, бачиш хвилю на таймлайні, ріжеш, міняєш швидкість, тон і гучність, зберігаєш у потрібному форматі. Усе в браузері, файл нікуди не вантажиться.

- **Вхід:** усе, що читає браузер (`decodeAudioData`), частота джерела зберігається (визначається за заголовком WAV/FLAC/MP3/OGG). Якщо браузер не читає файл (наприклад, M4A у Chromium без кодеків чи відео), працює запасне декодування через ffmpeg.wasm. Понад 2 канали: беруться перші два.
- **Монтаж** (`audio-core.js`): проєкт = список фрагментів джерела (початок, кінець, швидкість, тон, гучність, режим «плівка»). Розрізання, видалення, обрізка й «залишити виділене» лише міняють список; звук не копіюється. Скасувати/повернути: 100 кроків.
- **Дії над ділянкою:** виділення мишею (краї можна посунути) чи числами; без виділення діє фрагмент під курсором. Швидкість 0.25–4×, тон ±12 півтонів (без зміни тривалості: WSOLA у `dsp-core.js`; з прапорцем «як плівка» тон іде разом зі швидкістю), гучність −60…+24 дБ. На стиках невеликі фейди (3 мс) проти клацань.
- **Загальне:** гучність усього запису, fade in/out (лінійні), нормалізація до заданого піку (останній крок).
- **Експорт:** MP3 (64–320 кбіт/с; для низьких частот ліміт за правилами MP3), WAV (16/24/32 float, збирається без ffmpeg), OGG (Vorbis за якістю, ≈ вибраний бітрейт), M4A (AAC), FLAC (16/24). Частота: як у джерелі або 8000–48000 (для WAV/FLAC до 96000), канали: як у джерелі, моно, стерео.
- **Обробка:** збирання у Web Worker (`audio-worker.js`, запасний варіант: головний потік). Відтворення програє точно той самий результат, що й експорт.
- **ffmpeg.wasm** (`ffmpeg-loader.js`): обгортка лежить у `vendor/` (MIT), ядро `@ffmpeg/core@0.12.10` (~32 МБ) завантажується з CDN (jsDelivr, запасний unpkg) при першому експорті не в WAV і кешується в Cache API. Для перевірки без інтернету: `?ffcore=/шлях/до/папки/` з `ffmpeg-core.js` і `ffmpeg-core.wasm`.
- **Клавіші:** пробіл (грати), S (розрізати), Delete, Ctrl+Z / Ctrl+Shift+Z, Home/End, +/−, колесо (масштаб), Shift+колесо (гортання).
- Обмеження: пам'ять (звук тримається в `Float32`: година стерео 44.1 кГц ≈ 1,2 ГБ ×2 з копією у воркері), тому для дуже довгих записів краще різати на частини.
- Ключ localStorage: `ae_` (лише налаштування експорту й загальної гучності; файли не зберігаються).

Тести: `node audio-editor/test/audio.test.js`.
