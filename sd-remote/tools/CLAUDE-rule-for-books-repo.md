## Обкладинки й ілюстрації (генератор Stable Diffusion)

Картинки для книжок генеруються на моєму ПК через сайт-генератор. Роби це сам, у чат картинки не надсилай.

1. Скопіюй скрипт: `curl -sSL https://raw.githubusercontent.com/foonyresso/zbyrai/main/sd-remote/tools/sd_generate.py -o /tmp/sd_generate.py`
2. Запусти (змінна `SD_KEY` уже задана в середовищі). Приклад для обкладинки 3:4:
   `python3 /tmp/sd_generate.py --prompt "<теги англійською через кому>" --out <папка книжки>/cover.webp --ratio 3:4`
   - Скрипт сам додає ті самі три LoRA на початок промпта, мій негативний промпт, апскейл 1.65× і ADetailer для обличчя, тобто результат такий самий, як від кнопки на сайті. НЕ додавай LoRA й негативний промпт у свій текст.
   - Пропорції: `--ratio 1:1|2:3|3:4|4:5|5:7|9:16|9:21` (типово 9:16), `--landscape` для горизонтальних (напр. ілюстрація всередині: `--ratio 3:4 --landscape`).
   - Без обличчя/людей (пейзаж, предмет): `--no-adetailer`; без апскейлу: `--upscale 1`; без LoRA: `--no-lora`; інші LoRA: `--lora Назва:0.5`.
   - Спершу можна перевірити, що піде на сервер: додай `--dry-run`.
3. Промпт пиши як **теги через кому** (стиль Danbooru: `1girl, long hair, forest, golden hour, from below`), короткі фрази без довгих речень; спочатку якість і головне (`masterpiece, ...`), потім сцена, композиція, світло. Не повторюй негативні слова в позитивному промпті.
4. Відкрий результат, перевір, що картинка відповідає задуму; якщо ні, зміни промпт і повтори (інший `--seed`). Скрипт друкує, що саме відправив (промпт, розмір, налаштування): користуйся цим, коли пояснюєш мені результат.
5. Закоміть файл у репозиторій книжки.
6. Код виходу 2 означає, що ПК вимкнений: скажи мені, не вигадуй заміну.
