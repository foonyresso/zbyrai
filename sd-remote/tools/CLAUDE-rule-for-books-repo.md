## Обкладинки й ілюстрації (генератор Stable Diffusion)

Картинки для книжок генеруються на моєму ПК через сайт-генератор. Роби це сам, у чат картинки не надсилай.

1. Скопіюй скрипт: `curl -sSL https://raw.githubusercontent.com/foonyresso/zbyrai/main/sd-remote/tools/sd_generate.py -o /tmp/sd_generate.py`
   (якщо репозиторій приватний, візьми його через `add_repo`/клонування).
2. Запусти: `SD_KEY` уже заданий в середовищі. Команда:
   `python3 /tmp/sd_generate.py --prompt "<англійською, детально>" --out <папка книжки>/cover.webp --width 768 --height 1024`
   Для ілюстрацій усередині: `--width 1024 --height 768` (або потрібний розмір).
3. Відкрий результат (Read), перевір, що картинка підходить; якщо ні, зміни промпт і повтори (інший `--seed`).
4. Закоміть файл у репозиторій книжки.
5. Код виходу 2 означає, що ПК вимкнений: скажи мені, не вигадуй заміну.
Промпти пиши англійською: опис сцени, стиль, композиція, світло. Негативний промпт типово вже розумний.
