# Віддалений SD

Друг пише промпт на сайті → задача йде в чергу (Cloudflare D1) → воркер на твоєму ПК забирає її, генерує у Forge Neo й віддає картинку назад. Вхідні підключення до ПК не потрібні. Інструмент прихований від пошуку й не винесений на головну.

## Налаштування (один раз)

**1. База D1.** Cloudflare → Storage & Databases → D1 → Create → ім'я `zbyrai-sd`. У Console виконай вміст `functions/schema.sql` (можна повторно, нічого не зламається; для LoRA потрібна таблиця `sd_loras`).

**2. Підключення до сайту.** Workers & Pages → проєкт `zbyrai` → Settings:
- Bindings → Add → D1 database → змінна `DB`, база `zbyrai-sd`.
- Variables and Secrets → Add (тип Secret):
  - `WORKER_TOKEN`: довгий випадковий рядок (для твого ПК);
  - `ADMIN_PASSWORD`: твій пароль для адмінки;
  - `ACCESS_CODES` (необов'язково): готові акаунти `логін:пароль`, через кому.
- Після цього зроби Redeploy (або будь-який новий коміт).

**3. ПК.** Запусти Forge Neo з прапорцем `--api` (у `webui-user.bat`: `set COMMANDLINE_ARGS=--api`). Скопіюй у папку Forge файли `worker/sd_worker.py`, `worker/start-worker.bat`, а `worker.example.json` перейменуй у `worker.json` й встав той самий `WORKER_TOKEN`. Запускай `start-worker.bat`, поки ПК має генерувати.

**4. Акаунти.** Друг відкриває `/sd-remote/` і подає заявку (логін + пароль). Ти заходиш на `/sd-remote/admin.html`, вводиш `ADMIN_PASSWORD` і тискаєш «Відкрити доступ». Для нейронки зареєструй окремий акаунт так само й задай `SD_KEY=логін:пароль`.
Захист: заявка без підтвердження нічого не дає; максимум 20 заявок у черзі; після 8 хибних паролів вхід блокується на 15 хв.

## Сторінка
- **Ліворуч (приліплена панель):** перемикач «Базовий / Гнучкий» (у гнучкому ще «Картинка / Теги»), промпт і негативний з підсвіткою тегів, пропорції (1:1…9:21) із кнопкою вертикаль/горизонталь, розмір (довга сторона, крок 64), кроки 2–12, апскейл (довга сторона результату ≤ 2800 px), seed, ADetailer для обличчя (кнопка «⚙ Теги» відкриває вікно з окремими позитивними й негативними тегами), активні LoRA з повзунками сили −5…5.
- **Вага тегів:** виділи текст у промпті, під полем з'являться кнопки −100% −50% −10% «Норма» +10% +50% +100%. Для звичайних тегів виходить `(тег:1.1)`, для LoRA змінюється сила в `<lora:назва:сила>`; «Норма» повертає 1.0 (для LoRA: типову).
- **Центр:** вкладки «Генерація» (картинка або групи тегів), «LoRA» (список із ПК, метадані, тригер-слова, Додати) та «Історія».
- **Прогрес:** смужка показує реальний хід (черга, генерація за даними Forge, ADetailer, передача на сервер, завантаження в браузер за байтами).
- **Сервер вимкнений:** усе сіре, у центрі напис «Сервер зараз не доступний».
- Налаштування зберігаються в браузері (localStorage, ключ `sd_state2`).
- Теги: ~2400 англійських тегів із бази Кубика промптів; оновити: `node tools/build-sd-tags.mjs`.

## LoRA
Воркер читає список LoRA з Forge (`/sdapi/v1/loras`) і метадані поруч із файлами: `.civitai.info` (Civitai Helper), `.json` (Forge), службові поля `.safetensors`, прев'ю (`.preview.png` тощо). Список оновлюється при запуску воркера й кожні 5 хв, якщо змінився.

## Для апскейлу й ADetailer на ПК
**CFG, семплер, Shift і параметри Hires/ADetailer** на сайті не показуються: за замовчуванням їх задає `sd_worker.py` (Steps 8, Euler a, Beta, CFG 1.4, Shift 3; Hires: RealESRGAN_x4plus_anime_6B, 8 кроків, CFG 1.4, Shift 8, denoise 0.4; ADetailer face 0.75/0.27; кроки на сайті 2–12, типово 8). Будь-яке значення можна змінити в `worker.json`. На сайті крутяться розмір, кроки, апскейл, seed, ADetailer (лише обличчя), LoRA.
Апскейл працює через Hires. fix у Forge (апскейлер за замовчуванням `Lanczos`, змінюється в `worker.json`: `hr_upscaler`, `hr_denoise`). ADetailer потребує встановленого розширення ADetailer у Forge Neo; назви моделей у `worker.json` (`ad_face_model`, `ad_hand_model`, типово `face_yolov8n.pt` і `hand_yolov8n.pt`). Якщо ADetailer не спрацює, воркер сам повторить генерацію без нього.

## Обмеження
До 3 задач у черзі на людину, довга сторона до 1280 px (з апскейлом до 2560); картинки живуть 7 днів. Модель береться та, що зараз завантажена у Forge.

Тести: `node sd-remote/test/sd-client.test.js && node sd-remote/test/sd-core.test.mjs`
