# 12. Виробничі ланцюжки (production-planner)

## Інтерфейс
- Полотно — на весь екран; меню мінімальні, кнопки-іконки (як у Photoshop). Схему можна рухати: кожен блок вручну, авторозстановка, обертання/перегляд зв'язків.
- Додавання прямо на полотні: «плюсик» → вибір ресурсу/виробництва, кількість, хвилини/секунди; тягнути «повзунок/лінію» від вузла, куди рухається. Без лазіння по меню.
- Взяти ідеї готових планерів Satisfactory (ресурси, видобуток, переробка, машини).

## Зміст
- Зараз вкрай обмежено — жорстко розширити: набагато більше зразків, типів виробництва, вузлів.
- Покроково: руда → плавильня → злиток → кузня → меч (не руда одразу в меч). Приклад: лісоруб → ліс → колоди → дошки → майстер мечів (дошки на руків'я, залізна руда, шкіра для обмотки) → меч → магазин.
- Врахувати логіку «що куди йде» (пшениця не в кузню): продумана сумісність типів.
- Джерела ідей: Satisfactory, Conan Exiles та ін.
- **Розумний рандом:** обмеження — макс. довжина ланцюжка (напр. 4 етапи), діапазон входів на одне виробництво (напр. від 1 до 5 чи рівно 5), можливо дуже велике дерево.
- **Інші режими** (не лише виробництво): крафт предметів (Dota-стиль: два предмети зливаються в сильніший, кожен сам із інших; налаштування кроків і макс. кількості компонентів); дерево досліджень (напр. атомна бомба вимагає купи досліджень); перейменувати вкладку/модуль з «виробничі ланцюжки» на ширше (або лишити, запропонувати назви).
- Результат — для розробників: рандомити собі ідею ланцюжка здобуття предмета.
