# 04. Prompt Dice

- Нагадати автору: об'єднати з іншою схожою фішкою (була для Stable Diffusion; інший підхід, та сама суть). Автор скине архів з розширенням SD — подивитись і об'єднати.
- Режим **Flux** зараз нічого не змінює (ті ж теги); Flux потребує **живої мови**. Рішення: для кожного типу тегів (очі, волосся, шкіра тощо) — одне шаблонне речення живою мовою; якщо тегу нема — шматок пропускається; змінюються лише певні слова; умовні доповнення (напр. червоні очі, що світяться → «світяться»).
- **Gemini**: працює, але треба розбиратись (потрібні інструкції для Gemini); спершу об'єднати з розширенням, потім розширювати.
- Майбутнє: Prompt Dice і міні-Фотошоп (див. 02) зробити розширеннями Stable Diffusion; автор забуде — нагадати.

**Зроблено (манекен):** SD-плагін об'єднано з Кубиком: SVG-манекен з 30+ ділянками, повністю новий інтерфейс (манекен | вкладки з картками | промпт), розширені пози, фони, об'єктиви. Flux/Gemini для нових параметрів: загальний абзац «Additional details by body part» (повноцінні речення для них ще не написані).
