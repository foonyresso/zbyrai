# 04. Prompt Dice

- Нагадати автору: об'єднати з іншою схожою фішкою (була для Stable Diffusion; інший підхід, та сама суть). Автор скине архів з розширенням SD — подивитись і об'єднати.
- Режим **Flux** зараз нічого не змінює (ті ж теги); Flux потребує **живої мови**. Рішення: для кожного типу тегів (очі, волосся, шкіра тощо) — одне шаблонне речення живою мовою; якщо тегу нема — шматок пропускається; змінюються лише певні слова; умовні доповнення (напр. червоні очі, що світяться → «світяться»).
- **Gemini**: працює, але треба розбиратись (потрібні інструкції для Gemini); спершу об'єднати з розширенням, потім розширювати.
- Майбутнє: Prompt Dice і міні-Фотошоп (див. 02) зробити розширеннями Stable Diffusion; автор забуде — нагадати.

**Зроблено (манекен):** SD-плагін об'єднано з Кубиком: SVG-манекен з 30+ ділянками, повністю новий інтерфейс (манекен | вкладки з картками | промпт), розширені пози, фони, об'єктиви. Flux/Gemini для нових параметрів: загальний абзац «Additional details by body part» (повноцінні речення для них ще не написані).

**Зроблено (українські назви, групи, без дублікатів):**
- У вибірі все українською (`prompt-dice/ua-*.js`: словник «тег = назва»), у промпті лишаються англійські теги; назва англійського тегу видна у підказці чипа. Тест `test/mannequin.test.js` вимагає українську назву для кожного варіанта.
- Старі параметри (волосся, очі, обличчя, раса, одяг…) поділено на групи прямо в картці (`mk-spec.js`); де варіанти взаємовиключні, у заголовку групи «одне з групи» (розріз очей, зіниці, склера, вії; хвіст, коса, пучок, текстура волосся). Групи показуються на своїй ділянці манекена (хвости на тазі, роги на волоссі, помада на роті).
- Категорії манекена, що збігалися зі старими параметрами, влито в групи (`@id` у `mk-spec.js`); кожен тег має один «дім» (перевіряє тест). Нічого не загублено, крім навмисно прибраних тегів зі статтю (див. нижче).
- Стать задається лише параметром «Стать»: теги `*_girl/_boy`, `*_female/_male`, `bara`, `bishounen`, чоловічі «груди» з тегів тіла прибрано.
- Фон і ефекти тематик розбито на окремі теги (раніше один довгий «чип» на тематику).

**Адаптивна мова (на потім):** зараз інтерфейс лише українською. Словник `ua-*.js` стане таблицею перекладів `uk`, а мова обиратиметься за `navigator.language` з однаковим форматом `тег=назва` для кожної мови; ключ (англійський тег) не змінюється, тож промпти не зачепить. Поки що адаптивності немає.

**Зроблено (кольори й меню рас):**
- Кольори (`prompt-dice/colors.js`): 21 готовий квадратик + «веселка» для довільного кольору (береться найближча назва). Палітра з’являється в тій самій підгрупі, під її тегами, для вибраного тегу, що може мати колір (тегам без кольору нічого не додається); два кольори (різнокольорове волосся й очі, смугастий або градієнтний одяг) — дві палітри «колір 1» і «колір 2». Рандом сам вибирає колір (два різні) лише з готової палітри. Для волосся, очей, нігтів і незвичної шкіри є підгрупа «Будь-який колір» з палітрою; для крил, рогів, хвостів, вух, одягу, взуття, прикрас, макіяжу квадратики з’являються, коли такий тег вибрано, і колір додається до тегу («pink_bunny_ears», «red_thighhighs»). Тегам без кольору (поза, світло тощо) квадратиків немає.
- Меню особливостей раси (`race-data.js`): картка «Расові особливості» змінюється за вибраною расою (ангел: крила, німб, пір’я; демон: роги, крила, хвіст, ікла; кролик: вуха, хвостик-бомбончик, хутро; монстр: з чого складається…), світиться золотою рамкою; універсальні особливості лишаються нижче в згорнутому блоці. Додано раси: кіт, лис, вовк, пес, кролик, кінь, тигр, дракон, змія, птах, павук, рослина, слиз, монстр (теги нейтральні за статтю).
- Нова раса чи особливість: рядок у `RACE_MENU`, назви в `ua-race.js`; тест перевіряє, що теги меню існують.

**Колір лише палітрою; прибрано зайве:** теги кольорів (чорне/рожеве волосся, сині очі, червоні рукавички, білі панчохи, колір взуття, шерсті, зубів, язика, склери, фону, помади, тіней, лаку) прибрано — колір обирається палітрою під тегом (волосся й очі: палітра + двоколірні варіанти; нігті: «лак» + палітра). Рандом волосся й очей бере колір із палітри. Прибрано параметри «Вік», «Формат кадру» й «Формат аркуша» (формат і пропорції в SDXL/Flux виставляються вручну).
