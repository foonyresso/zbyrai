# 15. Суперечності, рішення за замовчуванням, складність

## Суперечності / колізії
1. **Назви ігор:** автор забороняє на сайті (09), але існує шар GodsDontDie у Loot Forge (gdd-*) та згадки «GodsDontDie» у ROADMAP/доках, `taste/` (довідка смаків із назвами ігор — закрита, `noindex`, не лінкується). Рішення: прибрати з інтерфейсу й опису сайту; внутрішні файли/taste лишити, але позначити як приватні; назву шару в UI — нейтральна («Розширений режим»).
2. **Loot Forge:** два режими → один (08); ROADMAP описує шар як окремий — оновити.
3. **Prompt Dice vs міні-Фотошоп vs Stable Diffusion:** очікування одного архіву від автора → блокуюче для злиття; рішення: підготувати Flux-живу мову зараз, злиття — коли отримаємо архів.
4. **D&D база самостійна, але інші можуть її читати** — не змішувати в зворотний бік (14).
5. **Sprite Cleaner → міні-Фотошоп:** вимога «не дуже ресурсожерливо» vs Warp/деформація — Warp відкладено.
6. **Автор: «поки нічого не починай, дай список і запитання»** vs інструкція координатора «виконуй, не питай». Прийняте рішення: виконано безпечні/малі правки; великі переробки (шари/маски, безкінечний Voxel, зоряні системи тощо) лишаються в списку.
7. **«Ідеї механік без назв ігор»** vs «базується на Ragnarok/WoW/Cube World» для формул — у розробницьких коментарях і docs можна, на сайті — ні.

## Складність (оцінка)
- Просто (годинна робота): перейменування кнопок планет, якір «назад», посилання GitHub, прибрати назви ігор, Інфо-кнопка, розкладка-незалежні гарячі клавіші, фікс Tessera-відстані, таблиці колонії (імена 90°), довгий журнал подій.
- Середньо: меню планет, фони, нові типи світів, динаміка стосунків, Flux-промпт, Tessera-меню/поворот, Voxel-біоми/руди/день-ніч, Loot Forge один режим, пружна фізика дерева, формули кривих.
- Складно: шари/маски/криві в редакторі, безкінечний світ Voxel, повноекранний планувальник з drag-схемою, зоряна система, генератор підземель, конструктор скілів.
- Відкладено (ресурсожерливо): Warp-деформація, 3D-конструктор монстрів, будівлі-замки, гібрид Sims+SimCity, великий космос Avarion.
