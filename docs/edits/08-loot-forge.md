# 08. Loot Forge

- Зараз зроблено два режими (звичайний + «GodsDontDie»), а автор просив накласти механіку зверху → **один режим**. Якщо розширений режим повторює все з простого — простий прибрати.
- Прибрати з інтерфейсу назву гри й будь-яку інформацію про неї (див. 09).
- **Інвентар:** виглядає як список; автор хотів візуальний інвентар (схожий на гру). Автор пізніше скине скріншот → нагадати на цьому пункті (чи згенерувати візуал через ChatGPT/Gemini, див. 09).
- Класів предметів небагато: лук, меч, сокира, шапка, аксесуар, простий лут тощо. Для кожного — проста власна іконка (не морочитись, щось намалювати).
- **Лишити:** картки та «слоти героя + карти» (виглядають круто, подобаються); слоти героя треба змінити (зміст не уточнено).
- Симуляція — автору незрозуміла, потрібне пояснення (прочитає пізніше).
- Опис/гумор у «кузні предметів» зник → повернути (див. також 12 про історії).
