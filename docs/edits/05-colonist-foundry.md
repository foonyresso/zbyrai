# 05. Колонія (colonist-foundry)

- **Назва:** перейменувати з англійської на українську — «Симуляція колонії».
- **Листочки колоністів:** подати інакше; візуально прикольно, але додаткові блоки внизу виходять за межі картки. Візуал — через промпт для ChatGPT/Gemini (див. 09), автор скине кращий варіант.
- **Стосунки — динамічні** (як RimWorld): сваряться → падають, хороші події → вирівнюються, залежать від настрою; можуть побитись, помиритись, подружитись, одружитись; хвороби за певних обставин; симуляція погоди й хвороб.
- **Таблиця стосунків:** зверху замість номерів — імена (повернути на 90° вертикально або розширити). У таблиці пріоритетів робіт (будівництво, поле, копання…) заголовки теж повернути на 90°, розділити лініями, щоб було схоже на таблицю й вужче.
- **Журнал подій:** зараз лише 3 — зробити довгу історію з прокруткою; при наведенні — детальніше.
- **Локація/поселення:** рандомно або вручну — планета, поселення, тип (місто/село), умови й проблеми, що впливають на настрій і події (пустеля: спека, здоров'я; джунглі: волога, хвороби).
- **Час:** автоперемотка; бажано погодинний крок (щогодини щось змінюється); періодичні ситуації/взаємодії та інші події, що впливають на настрій (обвал, напад монстра) залежно від професії: шахтар — обвал; мисливець — поранення/напад; кухня — порізав палець (−1); варта — напад бандитів. Події бувають загальні (глобальні), для професії або для однієї людини.
- **Історія конкретного колоніста:** при наведенні/виборі бачити лише його події (загальний розклад доби: сон → їжа → розмова → робота… плюс події, що відбулись у цих погодинних діях; без подій — пропускається).
- Багато більше професій/класів.
- Короткі історії колоністів трохи довші й розмаїтіші; більше імен (спільна бібліотека — див. 14).
