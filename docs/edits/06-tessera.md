# 06. Tessera

- **Меню:** фігури та ін. займають забагато місця, до налаштувань далеко крутити. Згрупувати й ховати (кнопки, що розкривають групи фігур); меню переробити загалом (стосується й усіх подальших меню).
- **Кольори** — в окреме місце: кнопка відкриває вікно (як у Photoshop), яке можна **закріпити** (не закривається).
- **Поворот фігур:** зараз можна крутити все полотно, але не самі фігури; «хаос» лише рандомізує розмір/обертання. Додати: повернути всі фігури одночасно вліво/вправо (не полотно) — це дає нові форми. Інші подібні навороти для розміру й форми.
- **Баг:** при зміні відстані між елементами або розміру зірки (їх «лінії» вертикальні) перемикаються зліва-направо/справа-наліво, хоча спрайт той самий → виправити (нестабільний напрям/фаза).
