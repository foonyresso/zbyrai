# 11. Idea Mixer

- Зараз надто обмежений і просто рандом ідей; ні до чого без продуманості.
- Прибрати назви ігор (напр. «Anno + Minecraft», «PoE/Shapez.io» — також помилка, що пише про «дерево вузлів на сотні вузлів» для гри, де їх майже нема) → лишити лише ідеї механік.
- Розширити: у кожної механіки — свої підпункти (рандомно додаються); взаємодія й узгодженість: залежно від жанру допустимі лише певні типи механік (не поєднувати нелогічне).
- Альтернатива/додаток: автору накидати ідей і для чого можуть знадобитись, відштовхнутись від цього.
- Статус автора: поки під питанням; відсутність працездатності, «ідея цікава, але треба дуже сильно розширювати».
