# 14. Спільні бази даних і D&D

- Створити спільну бібліотеку імен/предметів/назв, використовувану кількома інструментами (генерація предметів у Loot Forge, крафт у Планувальнику, колоністи, навички) — не окрема база для кожного генератора.
- Історії колоністів: довші й різноманітніші; більше імен.
- **Character Roller (листок D&D):** лише механіки D&D (SRD) — усе так, як у D&D, без сторонніх механік, щоб не суперечити тому, що гравці самі змінюють. Усі назви, предмети тощо — з D&D. База D&D — самостійна й нічим не збагачується іззовні; навпаки, інші інструменти можуть брати з бази D&D (напр. назви скілів). Нічого з інших баз не додавати в D&D-базу.
