# 09. Сайт загалом

1. **Кнопка «Інфо»** для всіх інструментів — у шапці, ПІСЛЯ назви інструмента, завжди на одному місці. Порядок шапки: назва сайту (назад на головну) → іконка й назва інструмента → «Інфо». Відкриває красиве спливаюче вікно по центру з описом (реалістичніший, менш «штучний» текст); закривається кнопкою OK, хрестиком або кліком поза вікном. Замінити нинішній окремий блок опису, що звужує робоче поле.
2. **Якір «назад»:** повернення з інструмента на головну має прокручувати до групи/картки цього інструмента (напр. «Кузня планет» вгорі видимої області), щоб не крутити заново.
3. **Посилання на GitHub:** верхнє посилання на GitHub автора прибрати; у футері «код на GitHub» — посилання на головну сторінку GitHub (github.com) як данина поваги, не на репозиторій/профіль автора. Жодних прямих посилань на особисті GitHub автора.
4. **Назви ігор:** не мають бути ніде (ні власних, ні чужих) — лише механіки (Idea Mixer, Loot Forge, Colonist, Планувальник та ін.).
5. **Візуальні рішення:** якщо не впевнені у візуалі — давати автору чіткий промпт (що має бути, без деталей розмітки; напр. листок персонажа: ім'я, вік, стать, статки, опис, бонуси) для ChatGPT/Gemini; автор вибере кращу картинку й скине. Це загальне правило для всього сайту — нагадувати й давати промпт щоразу, як тема доходить до візуалу.
6. **Принцип розробки:** механіки готувати як бібліотеку для майбутніх ігор автора (core легко інтегрувати); стороннім — бавитись/дивитись; код на GitHub відкритий, але не пропагується.
7. Зауваження автора до роботи: «багато що писав — на сайті досі нема, перевірити список дій»; зробити аудит невиконаного (див. ROADMAP).
