# 02. Sprite Sheet Cleaner → міні-Фотошоп

Мета: з часом щось схоже на Photoshop (повного Photoshop не буде, сказати що не влізе).

## Перейменування
Назва «чистильник спрайт-листів» не підходить: працюватимемо зі зображеннями різних типів → нова назва, що не йде в розріз з Photoshop (не «Photoshop» в назві). Разом із Prompt Dice планується зробити з них розширення для Stable Diffusion — нагадати автору в майбутньому, якщо забуде, коли вони дійдуть до адекватного вигляду.

## Клавіші
Гарячі клавіші (Ctrl+Z тощо) не працюють при українській/російській розкладці (працюють лише при англійській) → використовувати `event.code` (фізична клавіша), щоб працювало з будь-якою розкладкою.

## Інструменти
- Пензлик від руки + піпетка (вибрати колір із картинки і малювати ним). Ластик; налаштування пензлика й ластика спільні (малює/стирає).
- **Шари:** перетягнути друге зображення поверх → новий шар (був один, стало два), вибір шару для роботи. Приклад: лисичка-дівчинка + меч у руки.
- **Ctrl+T** (трансформація шару): рамка не по розміру всього шару, а по контуру ближніх непрозорих пікселів; рухати, масштабувати, тягти за кутки (вільна деформація/перспектива), за бічні/верхні — стискати/розширяти. Бажано **Warp** (сітка, точки-якорі, що фіксують ділянки). Якщо складно/ресурсожерливо — сказати «відкладаємо, не варто поки».
- **Маски шарів:** кожен шар може мати маску; вирізання фону = редагування маски, не пікселів.
- **Коригувальні шари** (прості й потрібні): **Криві** — обов'язково, бажано по каналах/кольорах, режим простої світлотіні, коригування окремого кольору.
- **Магічна паличка:** не одразу ховає, а виділяє; виділення показується заливкою кольору (колір вибирається), а не «мурашками»; з виділення робиться маска, що ховає залите. Може й повертати пікселі (Shift). Покращити (чи хоча б трохи): зараз після вирізки фону навколо дівчини Shift+клік по руці майже повернув усю картинку (блиск на руці, білий фон). Режим **обмеження ділянки**: окреме виділення-рамка, що не дає паличці виходити за межі; потім вимикається і працюємо з цілим зображенням (придумати назву фішки).
- Налаштування — для кожного інструмента свої; схожі інструменти (пензлик/ластик) об'єднані.

## Інтерфейс
- Нинішнє (кольори фону, ручні правки, нарізка, палітра, параметри атласу) не вміщується → ікони-кнопки (як у Photoshop), що відкривають вікна налаштувань; налаштування одного інструмента об'єднувати в одне меню.
- Праворуч на всю висоту — панель шарів (можливо ще щось). Поруч — відносно невеликі іконки.
- **Контекстні кнопки** біля зображення / місця кліку (або зверху/знизу) — з'являються по 1-5 залежно від можливостей, можуть бути відсутні.
- Нижні перемикачі (оригінал, рамки спрайтів, чорне/біле тло) перенести в магічну паличку або властивості маски.
- **Швидка прозорість маски** без заглиблення в налаштування: кнопки «приховано на 100% / 50% / 30%» і т.п., режим «блимання» (від 0 до 20-30%), щоб постійно бачити, що пропущено.
