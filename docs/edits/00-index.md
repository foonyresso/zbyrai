## Загальні принципи автора (діють для всього)
- Механіки пишуться так, щоб їх легко брати в майбутні ігри (core окремо від UI); іншим можна бавитись, код у відкритому GitHub, але прямо нічого не пропагується.
- Складне й ресурсожерливе — не робити, а сказати «відкладаємо»; спершу більше функціоналу, потім складне.
- Не ставити на сайт назви ігор (власних і чужих), лишати тільки ідеї механік.
- Не вказувати посилань на особистий GitHub автора.
- Візуальні рішення: не вигадувати самому, а давати автору промпт для ChatGPT/Gemini (див. 09).
- Автор просив: зробити список, перевірити суперечності, не починати одразу, задати уточнення. Інструкція координатора цього проєкту — виконувати без запитань, обираючи розумний варіант (рішення в 15).
