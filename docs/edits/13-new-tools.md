# 13. Нові ідеї інструментів

## Рандомайзер підземель (генератор кімнат/тайлів)
- Варіанти стилів: проста 2D з квадратними кімнатами; стиль Diablo (різні локації, що склеюються, декорації міняються); щось реалістичніше; можливо воксельний.
- Кімнати-тайли зі з'єднаннями (вихід лише зверху/ліворуч/праворуч/знизу, всі чотири, ліво+право тощо) мають стикуватись; відгалуження, секретні кімнати, пастки, лабіринт. Кількість кімнат від 3-4 до ~100 (максимум визначити за продуктивністю). Полотно з прокруткою/зумом.
- Різні кімнати в кількості; візуальний рандом поверх, щоб не кидалось в очі, але без великого навантаження.
- Ідеальне майбутнє: планування будівель/замків (креслення, кімнати, сходи, 2-3 поверхи) — автор визнає, що це, ймовірно, надто складно.

## Конструктор скілів
Дуже обширний: багато механік/алгоритмів-цеглинок; база з WoW, Ragnarok, Diablo, MU Online та ін.; щоб можна було відтворити практично будь-який скіл.

## Автоколаж фото
Заданий розмір або пропорції холста, закинути картинки — автоматично розставляє, можливо трохи обрізає для пропорцій; якщо зображення не вмістилось — його можна рухати; кнопка рандому «розкласти інакше».

## Патерни
Додаткові можливості й вигляд — за зразком https://patternico.com/ та https://palettemaker.com/ (для Pattern Maker/Tessera та палітр).

## Ігрові механіки-натхнення (сказати, що можна/не можна)
- **Avarion**: космос + будівництво корабля з блоків за правилами, ескадрилья, цивілізація, перемикання вид від третьої особи ↔ стратегія, баталії; дуже важко для відеокарт.
- Бажання: гібриди жанрів (шутер ↔ стратегія; Sims + SimCity; RimWorld-міні-версія з містом на пару сотень будівель і відносинами). Лише як мрія, не для сайту.
- **Spore**: конструктор монстра з частин (руки, ноги, хвости, роги, аксесуари, ефекти); автор допускає, що без 3D-скульптора не вийде, — розповісти, чи можна 2D-версію (рандомайзер монстриків).
