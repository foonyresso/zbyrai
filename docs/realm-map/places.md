# Точки інтересу, шахти й лігва

Дані: [`realm-map/data/poi-types.js`](../../realm-map/data/poi-types.js). Генерація: `core/pois.js`, `core/settlements.js` (шахти), `core/lairs.js`.

## Великі місця (до них веде мала дорога)

| Тип | Де | Примітка |
|---|---|---|
| Озеро | западина з озером ≥ 4 комірок | дорога веде до берега, найближчого до центру озера; площа в км² |
| Гора | локальний максимум гірського пасма, не ближче ніж 14 комірок до іншої | до одного піка на ~900 комірок суші |
| Старі руїни | будь-яка суша | назви: «Старі/Забуті/Прокляті/Сірі руїни …» |
| Давній пам'ятник | будь-яка суша | |
| Монастир чи храм | рівнини, пагорби | |
| Вежа мага | рівнини, пагорби, ліси | |
| Водоспад | річкові комірки | |

Кількість: ~1 на 170 комірок регіону (параметр щільності).

## Дрібні місця (до них ведуть стежки)

Галявина в лісі, покинута мала шахта (пагорби, гори), краєвидна площадка (пагорби, гори), старий пам'ятний знак, природний парк чи садок (рівнини, ліс), табір бандитів, придорожня капличка, хатина відлюдника. Плюс **лісові проходи**: стежки без пункту призначення між двома дорогами, що ідуть переважно лісом. Кількість: ~1 на 45 комірок регіону.

## Шахти

Лежать у пагорбах, горах і на піках, ≥ 5 комірок одна від одної, до 4 на регіон. Ресурс залежить від біому: пагорби (залізо, мідь, вугілля, сіль), гори (також срібло, золото, самоцвіти), піки (також мітріл). 15% шахт покинуті. До шахти веде мала дорога.

## Лігва

Див. [monsters-mountain.md](monsters-mountain.md), [monsters-forest.md](monsters-forest.md), [monsters-sea.md](monsters-sea.md). Види лігв: **лігво**, **місце відпочинку**, **лігво боса**. Рівні: 1 (звичайні), 2 (міні-бос), 3 (бос).

## Зачіпки

Кожне поселення в особливому стані, лігво й місце мають коротку сюжетну зачіпку (`hook`) із шаблонів `data/hooks.js`: напр. «{n} захопили {m}…». Це заготовка для квестів у грі.
