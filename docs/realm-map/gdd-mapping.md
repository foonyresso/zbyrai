# Відповідність грі GodsDontDie

Репозиторій гри лише прочитано (нічого не змінено). Гра вже має картки зі стабільними кодами (`World/Catalog/Cards/*.cs`, `Card { Code, Title, Weight, Fallback }`). Дані карти зведено до них у `realm-map/data/gdd-codes.js` (лише довідка, генерація не залежить).

| Карта | Картка гри |
|---|---|
| Велика / середня / мала дорога, стежка | `road.central` / `road.middle` / `road.small` / `road.trail` |
| Столиця провінції | `settlement.capital` (для великих провінцій гра має `great_capital`) |
| Центр регіону | `settlement.town`; містечко/село → `village`; хутір → `hamlet` |
| Шахта | `Mines.cs` (окремий каталог) |
| Руїни, вівтар/храм, табір бандитів, краєвид, затишне місце | `poi.ruins`, `poi.altar`, `poi.bandit_camp`, `poi.viewpoint`, `poi.cozy_spot` |
| Покинута шахта | `poi.dungeon`; лігво боса (tier 3) → `poi.boss_lair` |
| Порти | `port.main`, `port.fishing`, `port.island` |

## Різниці, які треба вирішити при перенесенні
- Розміри в грі задано в км (провінція 6–25 км, `province.small|medium|large|huge`), у карті масштаб `kmPerCell` (за замовчуванням 2 км). Для сумісності можна поставити розмір провінції за таблицею `ProvinceTypes`.
- Гра має чотири «ваги» провінцій (55/30/12/3 %) і шанс захоплення столиці монстрами 10 %; у карті стан столиці завжди «живий», стани лише у не головних.
- Ієрархії «регіон → центр» у грі ще немає: це нова картка (`region.*`) поруч з `ProvinceTypes`.
- Монстри та боси: окремі каталоги в `Fauna.cs`; дані з `data/monsters-*.js` переносяться як картки `monster.*` / `boss.*` з тими ж полями (`tier`, `variants`).
- Дороги в грі мають порти з `Road` та `Routes` (кількість морських шляхів, макс. довжина км); у карті морські шляхи будуються між усіма сусідніми портами, обмеження довжини ще варто додати.
- Формат: C# `init`-властивості, файли до ~500 рядків, `Fallback = true` для типу за замовчуванням.
- Генератор поселенців і планет: щойно буде видно їхні формати властивостей, поселенню карти додається `Peoples`/`Races` за культурою назви (6 культур у `name-banks.js`).
