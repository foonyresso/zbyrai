# Файли рас (формат 2)

Раса — це вид мешканців (народів у проєкті немає). Раси перемішані й живуть разом у межах виміру: кожне поселення населене кількома расами, а дуже маленькі (мало місця) — лише декількома. Кожна раса в окремому файлі `medieval-world/races/<id>.js` (`Atlas.registerRace`). Дублі зі списку (троль, демон, вампір, ящеролюд) об'єднані в одну расу; їхні різновиди описані в `lore`. Усього 89 рас у категоріях: людська/звичайна, ельфійська, мала, підземна, звіролюд, демонічна, стихійна, конструкт, рослинна, інсектоїдна, крилата, водяна, нежива, велетенська, рептилоїдна, драконяча, міфічна, ефірна, дикунська.

## Шаблон

```js
Atlas.registerRace({
  format: 2,
  id: "dwarf",                     // = назві файлу
  order: 100,
  name: "Гном",
  category: "гуманоїд",            // людина, гуманоїд, звіролюд, нежить, демон...
  weight: 3,                       // скільки їх загалом (вага при випадковому виборі, >0)
  size: "мала",
  habitat: ["mountain"],
  look: { tint: "#a07a5a" },       // колір розрізнення на карті (#rrggbb)
  lore: { description: "...", appearance: "...", temperament: "...", quarter: "...", buildings: "...", abilities: ["..."] },
});
```

## Склад поселення

Код: `raceMix` у `src/generation/world/races.js`. Кількість рас залежить від розміру поселення (за рівнем: 3, 5, 9, а містечка й більші вміщають усі раси). Вибір: зважене вибирання без повторів із вагою раси, за хешем поселення (стабільний для зерна). Будівлі трохи відрізняються за складом (відтінок `raceTint`). Шар «Раси» і підказка поселення показують склад у відсотках.

## Обмеження

Народів немає, лише раси: вони працюють у нескінченному світі й на «Материку» (`worlds/continent/core/races.js`). Рушій «Материк» не змінює від цього назви й геометрію.

## Раси по вимірах (версія 2.1, поля необов'язкові, старі файли працюють)

- Раса: `worlds: "all"` (за замовчуванням) або `["id виміру", ...]`; `worldWeight: { id: множник }`; `look.accent` (другий колір) і `look.body` (проста форма тіла з блоків для воксельного відтворення).
- Вимір: `races: { allow, deny }`, селектори `"<id раси>"` або `"cat:<категорія>"`. Раса, яку вимір прямо назвав у своєму `worlds`, проходить `allow`. Порожній підсумок = усі раси.
- Код: `Atlas.racesFor(worldId)` (кешується). Нескінченний світ бере `WSTYLE.id` (тема), «Материк» бере `params.theme` (або тип суші island/archipelago/pangea). Без теми — вимір `infinite`.
- Тест: `tools/atlas-registry.test.js` (посилання існують, у кожного виміру ≥8 рас). Категорія «демонічна»: демон, тіфлінг, інкуб, суккуб, біс.
