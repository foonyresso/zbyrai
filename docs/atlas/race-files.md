# Файли рас (формат 2)

Раса — це вид мешканців. Усі раси перемішані й живуть разом: кожне поселення населене кількома расами, а дуже маленькі (мало місця) — лише декількома. Кожна раса в окремому файлі `medieval-world/races/<id>.js` (`Atlas.registerRace`). Дублі зі списку (троль, демон, вампір, ящеролюд) об'єднані в одну расу; їхні різновиди описані в `lore`. Усього 33 раси.

## Шаблон

```js
Atlas.registerRace({
  format: 2,
  id: "dwarf",                     // = назві файлу
  order: 100,
  name: "Гном",
  category: "гуманоїд",            // людина, гуманоїд, звіролюд, нежить, демон...
  weight: 3,                       // скільки їх загалом (вага при випадковому виборі, >0)
  size: "мала",
  habitat: ["mountain"],
  look: { tint: "#a07a5a" },       // колір розрізнення на карті (#rrggbb)
  lore: { description: "...", appearance: "...", temperament: "...", quarter: "...", buildings: "...", abilities: ["..."] },
});
```

## Склад поселення

Код: `raceMix` у `src/generation/world/peoples.js`. Кількість рас залежить від розміру поселення (хутір 1–2, село 3, містечко 5, місто 9, столиця — майже всі). Вибір: зважене вибирання без повторів із вагою раси помноженою на `raceBias` народу провінції, за хешем поселення (стабільний для зерна). Будівлі трохи відрізняються за складом (відтінок `raceTint`). Шар «Народи й раси» і підказка поселення показують склад у відсотках.

## Обмеження

Народи й раси працюють у нескінченному світі. Рушій «Материк» (`worlds/continent`) про них не знає.
