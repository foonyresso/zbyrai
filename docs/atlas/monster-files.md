# Файли монстрів (формати 1 і 2)

Кожен монстр лежить в окремому файлі `medieval-world/monsters/<id>.js` і сам себе реєструє в `Atlas`. Список файлів збирає `registry.js` (`node tools/build-atlas-registry.mjs`), перевірка — `node tools/atlas-registry.test.js`. Світ нічого не знає про окремих монстрів: монстр сам каже, у яких біомах і світах з'являється.

Версії: **1** і **2** (додає необов'язкове `lore`). Файли формату 1 працюють без змін.

## Шаблон

```js
Atlas.registerMonster({
  format: 2,                          // версія формату: 1 або 2 (обов'язково)
  id: "my-monster",                   // = назві файлу; латиниця, цифри, дефіс
  name: "Мій монстр",                 // назва в інтерфейсі
  kind: "boss",                       // тип, див. нижче
  nature: "threat",                   // "magic" (магічний) або "threat" (загроза)
  alias: "Прозвисько",                // необов'язково
  variants: ["вогняний", "крижаний"], // необов'язково: різновиди
  spawn: { biomes: ["mountain", "peaks"], worlds: "all" }, // де живе: id біомів, "all" або список id світів
  order: 10,                          // порядок у списках
  lore: {                             // формат 2, необов'язково: опис для гри
    description: "Хто це", behavior: "Як поводиться, де сидить",
    abilities: ["що вміє"], drops: ["що з нього падає"],
  },
});
```

## Типи й відстані від поселень

Чим сильніший тип, тим далі від міст і сіл (таблиця `Atlas.monsterKinds` у `src/core/atlas.js`; відстань — від краю поселення, у метрах світу):

| Тип (`kind`) | Назва | Від міст | Від сіл |
|---|---|---|---|
| `weak` | Слабкі створіння | 1200 | 90; ближче за 700 — лише зрідка |
| `monster` | Звичайні монстри | 2200 | 700 |
| `other` | Інші (духи, мандрівні) | 1800 | 600 |
| `mini-boss` | Міні-боси | 3500 | 1400 |
| `boss` | Боси | 5500 | 2500 |
| `super-boss` | Супербоси | 8000 | 4000 |
| `world-boss` | Світові боси | 10000 | 5000 |

Біля міст монстрів немає зовсім. Слабкі підходять до сіл і хуторів, але рідко. Решта сильніших — тільки далеко.

Монстри окремих світів мають `spawn.worlds: ["<id світу>"]` (спільні для кількох світів перелічують усі). Боси світів — тип `boss`, `super-boss` або `world-boss`; тест перевіряє, що монстри з `lore.creatures`/`bosses` світу справді з'являються в ньому. Дублікати не створюємо: той самий монстр у двох світах — один файл із двома світами в `spawn.worlds`.

## Підключення

- Нескінченний світ: лігва й боси беруться з реєстру (`src/generation/world/realm-objects.js`), позиція — за хешем клітинки, тож однакова для того самого зерна. Підказка при наведенні показує назву, тип, природу і біом. Шар вмикається чіпами «Монстри» й «Боси».
- «Материк»: списки `src/data/realm/monsters-{mountain,forest,sea}.js` **генеруються** з файлів монстрів (`build-atlas-registry.mjs`), вручну їх не правити. Материк бере біоми deep, гірські та лісові; супербоси й світові боси там мапляться на найвищий ступінь.
