# Механіки нескінченного світу (шари й правила)

Усі перемикачі на вкладці «Світ», стан зберігається разом із картою. Чекліст виконання: [plans/world-generator-queue.md](../plans/world-generator-queue.md).

| Механіка | Файл | Що робить |
|---|---|---|
| Нові біоми («Нові біоми», `rlsb`) | `src/generation/world/sub-biomes.js`, `src/render/world/terrain-tiles.js` | Плями біомів із `biomes/*.js` (без `exclusive`, води, підземель) на суші поза рідними землями. Фарбують тайли, додають свій біом до точки: з'являються монстри й підземелля з цим біомом у `spawn.biomes`. Тег біому визначає, де пляма можлива (гори, ліс, болото, пустеля, сніг, рівнина). |
| Стежки до лігв і місць | `src/generation/world/object-trails.js`, `drawObjectTrails` | Дорога від найближчого поселення (до 2200): мала для значних місць, стежка для дрібних місць і лігв. Керується типами доріг «мала» і «стежка». |
| Ресурси шахт | `src/generation/world/mine-resources.js` | Руда чи камінь покинутої шахти: залізо, мідь, олово, свинець, срібло, золото, вугілля, сіль, камінь, самоцвіти, сірка, обсидіан; жила бідна/звичайна/багата. У підказці та кружком біля значка. |
| Небезпека («Небезпека», `rldn`) | `src/generation/world/danger.js`, `drawDanger` | Градієнт зелений → червоний за монстрами поруч і далекістю від поселень. За замовчуванням вимкнено. |
| Стани поселень («Стани поселень», `rlst`) | `src/render/world/settle-state.js` | Занепале: напівпрозорі будинки й завали; зруйноване: половина будинків руїни; покинуте: бліді, заростають; захоплене: червоні прапори. Від масштабу .5. |
| Раси (шар «Раси», `rlpp`) | `src/generation/world/races.js`, `src/render/world/race-style.js` | Народів немає, лише раси: див. [race-files.md](race-files.md). У «Материку» (`worlds/continent/core/races.js`) раси мають поселення; видно в картці, довіднику й експорті. |
| Океани («Суша і вода: Материки») | `src/generation/world/terrain.js` (`ocean()`, `wsetup()`) | Маска океанів (~40000) топить простір між материками: води між ними в 2–3 рази більше, ніж було; у воді лишаються нічийні острови, великі (~7000) і малі (~1500). Старт обирається на великому суходолі. Для «Архіпелагів» океани вдвічі слабші, «Суходіл» без змін. Перевірка: `node tools/world-oceans.test.js`. |
