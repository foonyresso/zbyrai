# Файли підземель (формат 2)

Підземелля у світі — це **локація**, а не згенерований лабіринт: лише позначка на карті, тип, мешканці й приблизний розмір (кількість кімнат, довжина ходів, площа, рівні). Кімнат ніхто не генерує; потім підземелля будуватиме гра. Кожен тип лежить в окремому файлі `medieval-world/dungeons/<id>.js` і сам себе реєструє (`Atlas.registerDungeon`). Після додавання файлу: `node tools/build-atlas-registry.mjs`, потім `node tools/atlas-registry.test.js`.

Підземелля міста в детальному вигляді (шар «Підземелля» поруч із «Світ навколо»: тунелі під вулицями, каналізація, склепи, лігво злодіїв) лишилося як було. Тепер ті самі типи (каналізація, катакомби, лігво злодіїв) є й локаціями на карті світу, але вже для **всіх** міст, а не лише для головного.

## Шаблон

```js
Atlas.registerDungeon({
  format: 2,                                   // потрібен формат 2
  id: "my-dungeon",                            // = назві файлу
  name: "Моє підземелля",
  anchor: { type: "poi", poi: ["ruins"] },     // до чого прив'язане, див. нижче
  size: { rooms: [10, 30], length: [500, 2000], area: [800, 4000], levels: [1, 2] }, // [мін, макс]: кімнати, довжина ходів (м), площа (м²), рівні
  inhabitants: ["нежить", "грабіжники"],       // хто живе
  monsters: [],                                // необов'язково: id монстрів із monsters/
  chance: 0.5,                                 // імовірність, що підходяще місце має таке підземелля (0..1)
  danger: 2,                                   // 1 слабка ... 5 для найсильніших
  spawn: { biomes: "all", worlds: "all" },     // у яких біомах (id, tag:, "all") і світах
  order: 100,
  lore: { description: "Що це" },
});
```

Необов'язкове поле `sim` для Симулятора підземель (`dungeon-sim/`): `sim: { tags: { flooded: 60, nests: 25 }, corr: 10, cave: true }`. `tags` — особливості кімнат і їх типова частка (%): flooded, rubble, tombs, webs, ore, altar, cells, lab, library, nests, roots, cache, crystals, blood; `corr` — типова частка коридорів (%), `cave` — овальні печерні кімнати. Без `sim` симулятор бере типові значення зі свого коду або загальні. Після додавання файлу: `node tools/build-atlas-registry.mjs` і `node tools/build-dungeon-types.mjs`.

## Прив'язка (`anchor`): де саме бувають підземелля

Підземелля не розкидані навмання: кожне стоїть там, куди й так ведуть дороги або стежки.

| `anchor.type` | Що | Уточнення |
|---|---|---|
| `city` | під містами й містечками | `tiers: [3,4,5,6]`: розмір міста (3 містечко ... 6 столиця) |
| `settlement` | у селах і хуторах | `states: ["ruined","fallen","abandoned","occupied","normal"]`: зруйноване, занепале, покинуте, захоплене монстрами, живе; зруйновані й захоплені мають підземелля найчастіше |
| `poi` | у місцях інтересу | `poi: ["ruins","temple","mage_tower","small_mine","mountain","monument","small_monument","bandit_camp"]` для нескінченного світу; нові світи вводять власні (`trunk-temple`, `blood-well`...) |

До місць інтересу веде мала дорога або стежка (так уже побудований нескінченний світ), тож підземелля туди потрапляють «логічно». Позначка ставиться біля міста чи місця (зі зсувом, щоб не перекривати значок).

## Нескінченний світ

Код: `src/generation/world/world-dungeons.js`, значок `drawDungeon` у `src/render/realm/icons-places.js`, шар у `src/render/world/realm-layers.js`. Позиція й вибір рахуються за хешем клітинки: для того самого зерна світ однаковий. Перемикач **«Підземелля світу»** (вкладка «Світ», чіп із підказкою) вмикає й вимикає шар; за замовчуванням увімкнено; стан зберігається в налаштуваннях. Позначки видно від масштабу, коли видно міста й місця. Наведи курсор: тип, небезпека, мешканці, кімнати, довжина ходів, площа, рівні, стан поселення.

Типи, що є в нескінченному світі: під містами (каналізація, катакомби, лігво гільдії злодіїв, підземна скарбниця), у поселеннях (підвали зруйнованого поселення, склеп, лігво загарбників, старий льох), у місцях (давнє підземелля, підвали зруйнованого замку, підземний монастир, лабораторія під вежею мага, покинута шахта, печерна система, курган-усипальня, сховок бандитів). Підземелля нових світів (`spawn.worlds`) у нескінченному світі не з'являються; їх відтворить гра.
