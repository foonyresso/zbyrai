# Файли біомів (формати 1 і 2)

Кожен біом лежить в окремому файлі `medieval-world/biomes/<id>.js` і сам себе реєструє. Які біоми дозволені якому світу, визначає **файл світу** за правилами нижче; біом нічого не знає про світи. Новий біом з відповідними тегами підхоплюється світами без правок світу чи ядра. Після додавання файлу: `node tools/build-atlas-registry.mjs`, потім `node tools/atlas-registry.test.js`.

Версії: **1** і **2** (додає необов'язкове `lore`). Файли формату 1 працюють без змін.

## Шаблон

```js
Atlas.registerBiome({
  format: 2,                         // версія формату: 1 або 2 (обов'язково)
  id: "my-biome",                    // = назві файлу; латиниця, цифри, дефіс
  name: "Мій біом",                  // назва в інтерфейсі
  color: "#8aa05a",                  // колір на карті
  tags: ["land", "temperate", "wet"],// теги для вибору біомів світом
  move: 1.5,                         // вартість кроку для доріг (необов'язково)
  speed: 14,                         // км/добу пішки поза дорогою (необов'язково)
  monsters: "forest",                // вид монстрів: "forest" | "mountain" (необов'язково)
  water: false,                      // true для води (необов'язково)
  fantasy: false,                    // true для фентезійних (необов'язково)
  lore: {                            // формат 2, необов'язково: опис для гри
    description: "Що це за місцевість",
    flora: "Рослинність і геологія",
    resources: ["що тут добувають"],
    hazards: ["небезпеки"],
    structures: ["споруди й локації"],
    // необов'язкові додаткові поля (ядро їх не читає): geology, fauna[], atmosphere, sounds, special,
    // gameplay, palette: [{ hex, name? }], variants: [{ name, description }] (біоми, об'єднані з цим)
  },
});
```

Біом, що належить лише одному світу, отримує тег `exclusive`: старі світи ховають такі біоми правилом `deny: "tag:exclusive"`. Наявні біоми не дублюємо: якщо в новому світі біом той самий під іншою назвою (наприклад, «Соснові Уступи» = `taiga`), у `lore.biomes` світу пишемо `{ id: "taiga", as_name: "Соснові Уступи" }`. Тест перевіряє, що назви біомів не повторюються.

## Теги

Теги вільні, але краще вживати наявні: `land`, `water`, `sea`, `deep`, `fresh` (вода); `cold`, `temperate`, `hot` (клімат); `wet`, `dry` (вологість); `plain`, `highland`, `mountain`, `forest`, `swamp`, `farmland` (рельєф і рослинність); `hills`, `canyon`, `shore` (рельєф); `stone`, `clay`, `glass`, `amber`, `mine` (матеріал); `mushroom`, `glow`, `dead`, `toxic`, `volcanic`, `bones` (особливість); `surreal` (абстрактні «виміри», не звичайна місцевість); `fantasy`, а також `exclusive` (лише для одного світу), `underground`, `cloud`, `canopy`, `crystal`, `ruins`, `blood`.

## Як світ обирає біоми

У файлі світу поле `biomes`:

```js
biomes: {
  allow: ["grass", "tag:mountain", "tag:cold+forest"], // або "all" (за замовчуванням)
  deny:  ["tag:water"],                                // необов'язково
  weights: { grass: 3, "tag:cold": 0.5 },              // необов'язково: множник частоти
}
```

Селектор: `"all"`, `"<id>"`, `"tag:a"` або `"tag:a+b"` (усі теги разом). Біом потрапляє у світ, якщо збігається з `allow` і не збігається з `deny`; його вага = добуток усіх `weights`, що збіглися (0 вимикає). Результат повертає `Atlas.resolveBiomes(world)`: список `{ biome, weight }`.

## Стан підключення

Реєстр, формат і вибір біомів працюють і перевіряються тестом. Рушій «Материк» поки що має власний список біомів у `worlds/continent/data/biomes.js` (з нього створено файли в `biomes/`); перехід рушіїв на читання `Atlas.resolveBiomes` робимо, коли автор надішле свій список біомів.

## Наявні біоми

Зі старого списку материка: `deep`, `sea`, `lake`, `grass`, `steppe`, `forest`, `taiga`, `enchanted`, `swamp`, `desert`, `tundra`, `wasteland`, `hills`, `mountain`, `peaks`; для нескінченного світу: `snow`; зразки: `savanna`, `jungle`, `volcanic`, `crystal`, `ashlands`.

## Біоми зі списку автора (264 файли)

Додані зі списку автора з файлу «біоми.txt» (записи 19–340). Схожі біоми об'єднано в один (їхні назви й описи лежать у `lore.variants`, а кольори додані до `lore.palette`), біоми, що вже є в репозиторії, не дублюються. Звіт: [biomes-import.md](biomes-import.md). Це біоми без тегу `exclusive`, тому `continent` (`allow: all`) їх бачить, коли рушій перейде на `Atlas.resolveBiomes`; для світів на `allow` із конкретним списком вони не заважають.

Відображення на наявні: Золота прерія → `steppe`; Савана на плато → `savanna`; Засніжені гори → `peaks`; Зачарований ліс → `enchanted`; Мертві землі → `wasteland`; Попелясті землі → `ashlands`; Вулканічна пустка → `volcanic`; Сосновий і бореальний ліс → `taiga`.
