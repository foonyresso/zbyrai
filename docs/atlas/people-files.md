# Файли народів (формат 2)

Народ — це культура провінції: менталітет, стиль міста й будівель, декор, споруди, одяг, зброя й палітра. Кожен народ лежить в окремому файлі `medieval-world/peoples/<id>.js` і сам себе реєструє (`Atlas.registerPeople`). Прототипи з таблиці були лише натхненням; назв чужих франшиз у файлах немає (це перевіряє тест). Усього 25 народів.

Після додавання файлу: `node tools/build-atlas-registry.mjs`, потім `node tools/atlas-registry.test.js`.

## Шаблон

```js
Atlas.registerPeople({
  format: 2,                       // потрібен формат 2 (старі файли формату 1 працюють як раніше)
  id: "my-people",                 // = назві файлу
  order: 100,
  name: "Мій народ",
  habitat: ["coast", "forest"],    // де живе: cold, hot, dry, wet, coast, mountain, forest, any
  mindset: "Менталітет",
  city: "Як побудовані міста",
  buildings: "Які будівлі",
  decor: ["прапори"], structures: ["маяки"], clothing: ["..."], weapons: ["..."],
  palette: [{ hex: "#8a6a3a", name: "охра" }],
  look: { walls: ["#8a7a52"], roofs: ["#4a6a3a"], trim: "#a83a3a", decor: "stilt", round: false }, // кольори #rrggbb; decor — знак на карті; round — круглі хатини
  raceBias: { dwarf: 2 },          // необов'язково: ваги рас у цьому народі (id рас з races/)
  lore: { description: "..." },
});
```

## Як це працює на карті

Файл: `src/generation/world/peoples.js`. Провінція (область навколо столиці) належить одному народові: його обирають за кліматом, горами, лісом і узбережжям столиці та хешем (те саме зерно дає ті самі народи). Будівлі в селах і містах фарбуються стінами, дахами й оздобою народу (`src/render/world/people-style.js`), деякі народи мають круглі хатини. Шар **«Народи й раси»** (чіп `rlpp`) показує межі провінцій і значки декору; за замовчуванням вимкнено, стан зберігається. Наведи курсор на поселення: народ і раси, які там живуть.

Старий нескінченний світ не змінюється, поки шар вимкнений.
