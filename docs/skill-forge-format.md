# Конструктор скілів: формат і цеглинки

Інструмент: `skill-forge/`. Черга задач: [plans/skill-forge-queue.md](plans/skill-forge-queue.md).

## Формат `zbyrai.skill`, версія 1
```
{ "format": "zbyrai.skill", "version": 1,
  "skill": { "name", "desc", "tags": [], "element": "fire",
             "cast": { "time", "cooldown", "cost", "resource": "mana|energy|rage|health|none", "charges" },
             "aim": { "mode": "enemy|ally|self|ground|direction", "range" },
             "root": [ Цеглинка ], "seq": 12 } }
Цеглинка: { "id": "b3", "t": "projectile", "p": { …параметри }, "c": [ вкладені цеглинки ] }
```
Правила вкладення: корінь ← доставка | ефект; доставка ← модифікатор | ефект | тригер; тригер ← ефект | доставка. Ліміти: 80 цеглинок, глибина 6.
Ефекти мають спільний параметр `to`: `hit` (цілі), `self` (гравець), `allies` (союзники поруч).
Імпорт відкидає невідомі цеглинки й неможливі вкладення та обрізає параметри до меж; файл новішої версії відхиляється з поясненням. Зміна формату = нова `version` + функція в `MIGRATIONS` (forge-core.js) + запис тут.

## Види цеглинок (≈57)
| Вид | Файл | Приклади |
|---|---|---|
| Доставка | `bricks/delivery.js` | миттєвий удар, удар зблизька, снаряд, промінь, конус, вибух, зона, аура, град ударів, пастка, стіна, прикликання |
| Модифікатор | `bricks/modifiers.js` | пробиття, ланцюг, розкол, самонаведення, затримка, повтор, утримання, накопичення, вибух при влучанні, критичний удар, добивання, вампіризм, втягування |
| Ефект | `bricks/effects.js` | шкода, шкода з часом, лікування, щит, відбиття, невразливість, приголомшення, уповільнення, заморожування, мовчання, страх, підкидання, провокація, відкидання, притягування, ривок, телепорт, невидимість, посилення/послаблення, мітка, зняття/очищення, ресурси |
| Тригер | `bricks/triggers.js` | при влучанні, при вбивстві, при критичному, коли закінчиться, через час, при малому здоров'ї |

## Як додати цеглинку
Дописати запис у відповідний файл `bricks/*.js` (або створити новий і підключити в `index.html` та тест — тест читає всю папку). Поля: `id`, `cat`, `name`, `icon`, `hint`, `params` (через `F.P.num/en/bool`) і функція оцінки: доставка `n/time[/hits]`, модифікатор `mod`, ефект `val`, тригер `fires`. Інтерфейс, опис і перевірка підхоплять її автоматично. Назви тільки власні.

## Оцінка
`forge-eval.js` рахує на манекенах (5 ворогів у колі радіусом 8 м, сила атаки = 100%): шкода, лікування, щит, контроль, охоплення, «ефективність» = сила / (1 + перезарядка/6 + ціна/30 + каст/6). Норма 0.8–1.3. Це орієнтир для порівняння, не симуляція бою.

## Зв'язок з Лабораторією дерев скілів
Кнопка «Для дерева скілів» копіює вузол (`role: "active"`, поле `skill` = повний файл скіла). `skill-tree` при імпорті дерева зберігає поле `skill` у вузлі (`tree-core.js`, `sanitize`). Окремого імпорту вузла в дереві поки немає: вузол вставляється в `nodes` JSON дерева вручну.

## Для Godot C#
Формат плоский і детермінований: `root` обходиться рекурсивно, `t` = ключ у реєстрі механік гри, `p` = параметри. Одиниці: метри, секунди, відсотки сили атаки. Оцінка потрібна лише редактору.
