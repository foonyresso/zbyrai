## Рішення за замовчуванням (автор не уточнив)

- Стиль: проста 2D з прямокутними кімнатами; додатково овальні «печери» для природних типів.
- Максимум кімнат 300 (генерація ~15 мс, карта малюється з відсіканням).
- Кімнати-тайли: ґратка клітинок, у кожній одна кімната; двері стикуються за побудовою.
- Візуальний рандом: легка варіація кольору плиток від хешу координат (без навантаження).
