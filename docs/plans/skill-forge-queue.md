# Черга: Конструктор скілів (`skill-forge/`)

Вимога автора (docs/edits/13, пункт «Конструктор скілів»): багато механік-цеглинок з відомих рольових ігор, щоб скласти майже будь-який скіл. Назви ігор на сайті не вживаємо; усі назви власні. Цільовий рушій: Godot C#, тому формат даних версіонований і не залежить від UI.

## Рішення
- Скіл = дерево цеглинок: **доставка** (снаряд, конус, зона…) → **модифікатори** (пробиття, ланцюг, розкол…) → **ефекти** (шкода, лікування, контроль…) → **тригери** (при вбивстві, при закінченні…) з вкладеними цеглинками.
- Кожна цеглинка описана даними в `bricks/*.js` (реєстр): нова механіка = новий запис, без змін ядра й UI.
- Формат `zbyrai.skill`, версія 1 (`docs/skill-forge-format.md`), `migrate()` для старих версій.
- З Лабораторією дерев скілів: вузол дерева може нести скіл (кнопка «Для дерева скілів» копіює вузол з полем `skill`); `role: 'active'`.
- Оцінка сили й вердикт балансу — оцінка на «манекенах» (кількість ворогів, сила атаки), не повна симуляція.
