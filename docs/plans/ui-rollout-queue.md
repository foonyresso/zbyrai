# Черга: єдиний стиль інструментів і доробки

Що тут: порядок робіт після генератора світів. Виконуємо по одній, від меншого до більшого; після кожної: тести, оновлення docs, пуш у main. Зразок інтерфейсу: симулятор підземель (`dungeon-sim/`: полотно на весь екран, `.rail` з іконками ліворуч, `.drawer` з панелями, `.bar` внизу). Не чіпати: Кузню планет, симулятор підземель, колонію, «Материк»/medieval-world.

Статуси: ○ чекає, ✱ у роботі, ✓ зроблено, ✗ не вийшло / пропущено.
