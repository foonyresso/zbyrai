# Принцип інтерфейсу: полотно + іконки

Для всіх генераторів і подібних інструментів (потім переробити):

- Є **полотно**, де відображається те, що створюємо/генеруємо, як у Photoshop. Полотно займає **весь екран**, не обрізане і не «у вікні».
- Усі меню й налаштування: **іконки по боках** (як у Photoshop), щоб не захаращували екран. Панелі розкриваються з іконок.
- Дані (параметри, інформація) подаються **акуратно, мінімалістично**, поверх полотна, не громіздко.
- Виняток: **«Симуляція колонії»**: працює інакше, її переробляти окремо й по-іншому.
- Доповнює правила проєкту: збереження/обмін у верхній панелі, блок «Що це», підказки на кнопках, українська, єдиний стиль заголовків.
