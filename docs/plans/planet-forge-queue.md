# Кузня планет: черга задач

Джерело: `zbyrai-edits/01-planet-forge.md` (правки автора) + `docs/plans/ui-canvas-principle.md`. Виконується по одній, від меншого до більшого. Статус: ○ черга, ✱ у роботі, ✓ зроблено, ⏸ відкладено.

| № | Задача | Пріоритет | Статус |
|---|---|---|---|
| 1 | Фони: випадковий тип (зорі, рухомі зорі, туманність, галактика, порожнеча), у кожного свої налаштування; входить у «Рандом» | висока | ✓ |
| 2 | Менше води: типові значення води в земного типу нижчі (.62 → .48) | висока | ✓ |
| 3 | Типи світів: континентальний (перший), пангея, архіпелаг, вулканічний архіпелаг (нова група «Типи світів», файл `planet-kinds-worlds.js`). Небесні архіпелаги: див. пункт 7 | висока | ✓ |
| 4 | Планета-місто: переробити візуально (райони, тонкі магістралі, рідкісні енергополя замість диско-кулі) | середня | ✓ |
| 5 | Полотно на весь екран, меню й налаштування іконками по боках (принцип полотна): іконки справа відкривають панелі (тип, зерно, фон, поверхня, небо, експорт), паспорт зліва, Esc закриває | середня | ✓ |
| 6 | Зоряна система: зірка (справжні й вигадані, чорна діра), планети на орбітах, клік відкриває планету, два вигляди (скорочений / справжні відстані з колесом масштабу) | середня | ✓ |
| 7 | Літаючий континент (не планета): окремий вигляд плит суші в повітрі, річки й водоспади за краї, мости, порожнеча замість океану | низька | ✓ |

Примітки: «Небесні архіпелаги» з правок = пункт 7 (разом з літаючим континентом). Перейменування «Материки → Архіпелаг» стосується Атласу, не цього інструмента.
