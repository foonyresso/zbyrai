# Інструменти: що з кожним робити

Усі пункти про перехід на «полотно на весь екран + іконки» ([принцип](ui-canvas-principle.md)), якщо не сказано інше.

| Інструмент | Що зробити |
|---|---|
| Генератор міст і світів (Medieval World) | **Пріоритет №1.** Меню занадто громіздке й велике: зробити мінімалістичним. Влити карту королівств. Довести до робочої версії. Див. [medieval-world-merge.md](medieval-world-merge.md) |
| Воксельна лабораторія (створення світу) | Не у вікні, а на цілому полотні; зверху налаштування й інформація |
| Кузня планет | Зображення планети на весь екран; поверх меню, деталі, інформація |
| Листок D&D | Напевно теж можна в такому вигляді |
| Планувальник виробничих ланцюгів | Однозначно переробити |
| Криві балансу | Напевно теж переробити |
| Змішувач ідей | Переробити; можна будувати з **ланцюжків**: що з чим іде, за чим і куди, що з чим синхронізується, від чого залежить |
| Редактор скілів | Однозначно; майже готовий, але полотно обрізане, а меню окремо. Потрібно: полотно на весь екран, меню іконками |
| Кузня предметів | Так само |
| Мозаїка фігур | Переробити за принципом |
| Чистильник спрайт-листів | Переробити за принципом |
| Конструктор візерунків | Переробити за принципом |
| Кубик для промпту | Повністю переробити інтерфейс: зараз жахливо незрозумілий |
| Симуляція колонії | Виняток: переробляти по-іншому |
