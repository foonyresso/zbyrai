# Версії форматів збережень

Що тут: зміни форматів JSON, що можуть вплинути на старі файли. Нова версія завжди читає старі.

| Інструмент | Версія | Що змінилось |
|---|---|---|
| Проект Атлас (`medieval-world`) | без номера | «Світи» в інтерфейсі стали «Вимірами» (id, файли й посилання `#w=<id>` без змін); вибір виміру дає новий випадковий світ. |
| Проект Атлас (`medieval-world`) | без номера | Прибрано народи: немає `peoples/`, `Atlas.registerPeople`, `lore.peoples` у світах, `people`/`peopleName`/`look` в експорті «Материка». Старі файли читаються, зайві поля ігноруються. Основний світ «Материки»: між материками велетенські океани з нічийними островами, тож те саме зерно дає іншу карту, ніж раніше; старі файли `.json`/посилання зберігають зерно й налаштування, а не карту. Шар «Народи й раси» (`rlpp`) тепер «Раси», збережений стан шару діє. |
| Колаж фото (`photo-collage`) | 1 → 2 | Додано `mode` (режим розкладки: tree, rows, columns, grid, hero) і `tiles[]` (рамка `x,y,w,h`, наближення `z`, зсув кадру `fx,fy` кожного фото за порядком). Файл версії 1 читається як режим `tree` без даних фото. Фото в JSON не входять. |
| Колаж фото (`photo-collage`) | 2 → 3 | Додано `blank` (true = фото вимкнено, на їхніх місцях прямокутники кольору, інвертованого до фону). Режим перетягування «Рамка» замінено на «Обмін місцями» (у JSON не зберігається; рамки `tiles[]` після обміну записуються як є). Файли версій 1 і 2 читаються, `blank` за замовчуванням false. |
| Конвертер зображень (`image-converter`) | 1 | Перший формат JSON: `fmt`, `q{webp,jpeg,avif}`, `maxKB`, `bg`, `ratio`, `ca`, `cb`, `w`, `maxSide`, `noUp`, `suffix`, `thumb`, `tiles[]` (`name`, `z`, `fx`, `fy`; кадри застосовуються до фото з тим самим іменем файлу). |
| Криві балансу (`balance-curves`) | без номера | Додано тип кривої `custom` з полями `expr` (формула) і `pl` (підписи a, b, p), а також `waves.hpScale` (крива множника HP хвилі). Старі файли читаються: тип лишається, `hpScale` береться за замовчуванням (×1). |
| Кубик промптів (`prompt-dice`) | 1 → 2 | Файл `.json` має `version: 2`. Додано нові параметри манекена (id `x_*`, `pl_*`, `zt_*` у `snapshot.slots`; за замовчуванням `mode: "off"`) і поля стану інтерфейсу в `pd2_state` (`zone`, `view`, `whole`, `wtab`). Файли версії 1 імпортуються без змін: відсутні параметри просто вимкнені. Файл версії 2 у старому Кубику відкриється, невідомі параметри ігноруються. |

- Раси 2.1: необов'язкові `worlds`, `worldWeight`, `look.accent`, `look.body` у расі та `races {allow, deny}` у вимірі. Склад поселень у виміру з обмеженнями змінюється для того ж зерна; в інших вимірах лише додались нові раси (зерно дасть інший склад через збільшений список).
- Атлас, лор поселень (`preset.settle` у вимірі): необов'язкове `{max, dens, ruin, names, roads}`. `max`: найвищий ранг поселень (6 усі, 3 без столиць, 2 лише малі, 0 хутори, −1 немає); `dens`: множник густоти; `ruin`: частка зруйнованих/покинутих (0–1, стартове місто живе); `names`/`roads`: власні назви рангів і доріг для Бестіарія. Без `settle` усе як раніше. Дороги йдуть за рангом нижчого кінця, тож без великих міст великих доріг нема. Для виміру з `settle` те саме зерно дає іншу розстановку поселень.

## Атлас 2.0
- `atlas2-params` версія 1: seed, size, worldType, provinces, regionsPerProvince, density, rugged, riverDensity. Світ відновлюється детерміновано.
- `atlas2-city` версія 1: експорт детального міста (кнопки «Копіювати/Завантажити JSON» у плані міста): поселення, райони, вулиці, площі, споруди. Місто детерміноване від зерна й номера поселення, у світ не зберігається.
- `atlas2-world` версія 1 (додано поле `landmarks`: місця за містами, зворотно сумісно): повний експорт (провінції, регіони, поселення, дороги, морські шляхи, шари в RLE).
- `atlas2-dungeon` версія 1: експорт підземелля (кнопки «Копіювати/Завантажити JSON» на екрані підземелля): вид, зерно, рівень, глибина, поверхи (кімнати, коридори, двері, монстри, пастки, скарби, сходи) і ходи в інші підземелля. Саме підземелля відновлюється детерміновано з зерна світу й номера (`<id поселення>.<n>`).
