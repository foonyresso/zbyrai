# Правила файлів і документації

- Один файл на механіку чи функцію, коли файл великий. Файли не повинні розбухати: для нового елемента краще новий файл. Орієнтир: понад ~800 рядків = розбити (див. [large-files.md](large-files.md)).
- Логіка (`*-core.js`, без DOM) окремо від інтерфейсу (`app.js`, `*-ui.js`) і даних (`*-data.js`).
- Документацію теж ділити за темами й групами: окремі файли в `docs/` і `README.md` в інструменті; не складати все в одну сторінку.
- Навігатор [NAVIGATION.md](NAVIGATION.md) оновлювати при кожній зміні структури.
- Великі тексти від користувача (з повтором і водою): стискати й оптимізувати, але зберігати зміст і всі деталі; нічого не губити.
- Робота йде прямо в `main`, без окремих гілок і PR; якщо пуш у `main` заблоковано, повідомити, а не обходити захист. Кожну нову роботу починати в новому треді.
