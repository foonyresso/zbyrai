# Симуляція поселення (`settlement-sim/`)

Що тут: карта файлів інструмента. Піксельне містечко на 20 жителів, світ 1120×800, камера за замовчуванням показує все місто (удвічі далі, ніж у демо), зум колесом. Збережень немає (сесія щоразу нова; `?seed=…` змінює розкладку).

## Порядок скриптів (`index.html`)
механіки (`mechanics/{rng,needs,schedule,combat,spawner,pathgrid}`) → спрайти (`px`, `frames`, `pose`, `gear`, `biped`, `beasts`, `nature`, `props`, `buildings`, `people`, `jobs`, `monsters`) → `layout`, `ground` → `sim-core`, `fx`, `routine`, `social`, `defend`, `animals`, `render`, `sim-step` → `app`.

## Файли
| Файл | Що |
|---|---|
| `px.js`, `frames.js`, `pose.js`, `gear.js`, `biped.js`, `beasts.js` | піксельні примітиви (3 тони + контур), кадри й пози людини, звірі й монстри (з демо захисників) |
| `nature.js`, `props.js`, `buildings.js` | дерева, фонтан, лавки; будинки, дім старости, таверна, крамниця, церква, кузня, комора, вежі й стіни: усе намальоване кодом, без зовнішніх зображень |
| `people.js`, `jobs.js`, `monsters.js` | вигляд людей за класом/професією, 20 професій, вигляд монстрів |
| `layout.js` | розкладка: 19 домів + дім старости, стіни з брамою, дороги, площа, ставок, парк, поля, точки призначення; сітка перешкод (тест: `test/layout.test.js`) |
| `ground.js` | одноразовий малюнок землі |
| `sim-core.js`, `sim-step.js` | стан `S`, час (12 с = година), рух з зіткненнями, крок симуляції |
| `routine.js`, `social.js` | розпорядок (сон удома з «zZZ», обід, робота, відпочинок), розмови й вітання |
| `defend.js` | тривога, бій мешканців, ШІ монстрів, смерть (оговтання вдома за ~22 с) |
| `animals.js`, `fx.js`, `render.js`, `app.js` | тварини, ефекти й емоції, малювання (ніч + вікна), інтерфейс і камера |

## Правила
- Логіка потреб/розкладу/бою/хвиль/шляхів живе в `mechanics/`, без DOM; інструмент лише комбінує.
- Дані користувача (вирізки з `npc-demo/assets`) не використовуються і в репозиторій не потрапили.
