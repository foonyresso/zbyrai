Що це

Конструктор візерунків: бере шматок будь-якого зображення й розкладає його в безшовний візерунок з дзеркалами, сотами, калейдоскопом або розеткою.

Для чого

Для фонів, текстур, тайлів для ігор, обгортки, тканини, шпалер. Готовий візерунок можна покласти поряд скільки завгодно разів, шви не видно.

Як користуватися

  1. Завантаж зображення: «Обрати файл», перетягни файл у вікно, Ctrl+V або «Демо».
  2. Обери режим і перетягни рамку виділення по зображенню: це «зерно» візерунка.
  3. Крути повзунки і ефекти справа, дивись результат у превʼю.
  4. Збережи кнопками угорі: тайл PNG, полотно PNG, копіювання або посилання.

Джерело

Відпустіть, щоб завантажити

Перетягніть виділення по зображенню, колесо миші змінює розмір. Файл можна перетягнути сюди або вставити через Ctrl+V.

Режим

Візерунок

Ефекти кінцевого результату

Ефекти діють на готовий візерунок, а не на текстуру: піксель-арт видно за будь-якого масштабу. Піксель-арт, хвиля, сканлінії, зерно й нахил потрапляють лише в експорт полотна; у PNG-тайл йдуть тільки колірні ефекти, щоб він лишався безшовним.
