# Pattern Maker: конструктор візерунків

Бере невелику ділянку зображення й розмножує її дзеркальними відбиттями за групою симетрії, тож шви збігаються
автоматично при будь-якому вмісті. Окремий режим «Безшовна текстура» робить із зображення плитку без дзеркал.

| Режим | Симетрія |
|---|---|
| Дзеркальна сітка | pmm, прямокутник ×4 |
| Калейдоскоп | p4m, ×8 |
| Соти | p6m, ×12 |
| Трикутна | p3m1, ×6 |
| Безшовна текстура | без дзеркал, зсув на половину й змішування |

## Як відкрити

Скачай цю папку й відкрий **`index.html`** подвійним кліком. Встановлення й інтернет не потрібні.

Джерело: обрати файл, перетягнути зображення у вікно, вставити з буфера (**Ctrl+V**) або взяти вбудоване демо.
Виділення на джерелі: перетягування рухає, колесо миші й повзунок змінюють розмір, повзунок повертає.
Експорт: PNG-тайл (256 до 2048 px) і PNG-полотно заданого розміру (за замовчуванням 1920×1080) або копіювання в буфер.
Режим «Піксель-арт» вимикає згладжування.

## Перевірка математики

Потрібен лише Node: `node test/fold.test.js` перевіряє періодичність кожного режиму, неперервність через краї,
належність результату базовій області, групову симетрію й відсутність швів на справжніх пікселях.
