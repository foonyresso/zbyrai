# Pattern Maker: конструктор візерунків

Бере невелику ділянку зображення й розмножує її дзеркальними відбиттями за групою симетрії, тож шви збігаються
автоматично при будь-якому вмісті. Окремий режим «Безшовна текстура» робить із зображення плитку без дзеркал.

| Режим | Симетрія |
|---|---|
| Дзеркальна сітка | pmm, прямокутник ×4 |
| Калейдоскоп | p4m, ×8 |
| Соти | p6m, ×12 |
| Трикутна | p3m1, ×6 |
| Безшовна текстура | без дзеркал, зсув на половину й змішування |
| Розетка | мандала: N-кратне дзеркальне складання навколо центру (не вимощується, експорт лише полотном) |

## Як відкрити

Скачай цю папку й відкрий **`index.html`** подвійним кліком. Встановлення й інтернет не потрібні.

Джерело: обрати файл, перетягнути зображення у вікно, вставити з буфера (**Ctrl+V**) або взяти вбудоване демо.
Виділення на джерелі: перетягування рухає, колесо миші й повзунок змінюють розмір, повзунок повертає.
Експорт: PNG-тайл (256 до 2048 px) і PNG-полотно заданого розміру (за замовчуванням 1920×1080) або копіювання в буфер.

## Ефекти кінцевого результату

Діють на готовий візерунок, а не на текстуру-джерело, тому видні за будь-якого масштабу.
Піксель-арт (розмір пікселя 1–48 px), палітри (Game Boy, CGA, PICO-8, сепія, неон, «Обсидіан і золото», монохром),
дізерінг Bayer 4×4, постеризація, лінза (опуклість/увігнутість), вир, хроматична аберація, рельєф і контури (Собель), градієнт-мапи (Вогонь, Океан, Ліс, Сутінки, Лід, Золото), віньєтка, відтінок/насиченість/яскравість/контраст, інверсія, хвиля, сканлінії, зерно, нахил візерунка.
Кнопка «Сюрприз» ставить випадкові повзунки й 2–4 випадкові ефекти.
Біля кожного повзунка є кнопка ↺ (скинути одне значення), а «Скинути все» повертає всі повзунки й ефекти до початкових.
У PNG-тайл потрапляють лише колірні ефекти (разом з палітрами й градієнт-мапами), щоб він лишався безшовним; з ефектами полотно не більше 16 мегапікселів.

## Випадкове зображення

Кнопка «Випадкове» бере випадкове фото з picsum.photos, а якщо воно недоступне, з Вікісховища. Це єдина дія, що звертається до мережі
(ваші дані не надсилаються). Пошук у Google з веб-сторінки неможливий: немає відкритого API без ключа й дозволу CORS.

## Перевірка математики

Потрібен лише Node: `node test/fx.test.js` перевіряє ефекти (піксель-блоки, належність палітрі, дізерінг, колір, розетку), а `node test/fold.test.js` перевіряє періодичність кожного режиму, неперервність через краї,
належність результату базовій області, групову симетрію й відсутність швів на справжніх пікселях.
