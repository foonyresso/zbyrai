# Voxel World Lab: воксельна лабораторія

Об'ємний світ із блоків (на відміну від плоскої карти Medieval World). Малюється на WebGL (без бібліотек): світ розбитий на чанки 16×16, у меш потрапляють лише видимі грані.

- **Генерація** за зерном: шум Перліна з октавами (масштаб, деталізація, різкість), рівень води, «острів», рівнинність, лінія снігу;
  біоми за висотою й вологістю (трава, пісок, камінь, сніг), **печери** 3D-шумом, **руди** (вугілля, залізо, золото) всередині каменю, **дерева** на траві.
- **Камера**: у режимі «Дивитись» перетягування лівою кнопкою обертає світ як 3D-модель (вгору, вниз, вліво, вправо), права кнопка чи Shift+перетягування панорамує, колесо масштабує; на дотику один палець обертає, два масштабують і панорамують. Кнопка «Перспектива/Ізометрія» перемикає проекцію, «Скинути вид» (R) повертає ракурс.
  У режимах «Ставити» й «Ламати» ракурс не скидається, а лівий клік працює з блоками. Камера в них рухається клавішами W A S D / стрілки (Shift швидше), Q E обертають, середня кнопка миші панорамує, права з перетягуванням обертає, колесо масштабує. Пробіл усюди створює новий світ.
- **Розмір світу** до 512×512 блоків (32×32 чанків), крок 16. Меш будується порціями за кадр, найближчі до камери чанки першими, тож інтерфейс не підвисає. Змінений блок перебудовує лише свій чанк. Для великих світів перегенерація повзунків відкладається трохи довше.
- **Видимі грані**: грань потрапляє в меш, лише якщо сусід — повітря, вода чи листя. Блоки під поверхнею не малюються, а чанки поза кадром відкидаються. Під списком блоків показано, скільки граней реально в меші.
- **Зріз за висотою** показує внутрішність і печери з «кришкою» на рівні зрізу, підсвітка блока під курсором.
- **Будівництво**: «Ставити» додає блок до грані, на яку клікнули (цегла, дошки, камінь, дерево та ін.), «Ламати» (або Shift+клік, права кнопка) прибирає; Ctrl+Z скасовує.
- **Експорт**: MagicaVoxel `.vox` (до 256 вокселів на сторону, для більших світів недоступний; палітра кольорів блоків), JSON зі стисненням серіями (і імпорт), картинка PNG, карта висот PNG.

Стан повзунків зберігається в браузері (`vx_…`). Правки блоків входять в експорт, але нова генерація їх замінює.

## Як відкрити

Скачай цю папку й відкрий **`index.html`** подвійним кліком. Встановлення й інтернет не потрібні.

## Перевірка

Потрібен лише Node: `node test/voxel.test.js` (визначеність, межі, вода, дерева, печери, руди, порядок обходу, видимість граней, чанковий меш і culling, промінь для вибору блока, світ 512×512, `.vox`, JSON).
