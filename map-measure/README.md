# Вимірювач на карті (`map-measure/`)

Що тут: карта планети (Esri World Imagery або OpenStreetMap, без ключів), на якій міряємо відстань між точками й площу фігури. Відстань і площа геодезичні (кругла Земля).

- Режими: лінія (сума відрізків), фігура (площа й периметр), перетягування точок, підписи відрізків.
- Одиниці: м, км, милі, фути; м², га, км², акри.
- «Ідеї»: коло від точки, перенесення копії фігури в інше місце зі справжнім розміром, антипод, закладки, координати центру.
- Пошук місця: Nominatim. Файли: GeoJSON (зберегти, імпорт, копіювати), друк.
- Файли: `measure-core.js` (математика, GeoJSON), `app.js` (карта й інтерфейс), `extras.js` (коло, копія фігури, антипод, закладки), `vendor/` (Leaflet 1.9.4, ліцензія BSD-2).
- Тест: `node map-measure/test/measure.test.js`. Ключ localStorage: `mm_state`, `mm_panel`.
