# Конструктор скілів: збери здібність з цеглинок

Скіл = дерево цеглинок чотирьох видів: **доставка** (як досягає цілей), **модифікатор**, **ефект**, **тригер**. ≈57 цеглинок, 18 готових прикладів, випадковий скіл, прев'ю на п'яти манекенах (вид зверху), груба оцінка сили й вердикт балансу, текстовий опис, скасування/повтор (Ctrl+Z / Ctrl+Shift+Z), пробіл запускає прев'ю.

Збереження й обмін у верхній панелі: Імпорт, Копіювати JSON (формат `zbyrai.skill`, версія 1), Для дерева скілів, Копіювати опис, Друк, Зберегти .json. Стан зберігається в браузері (ключ `sf_state`).

Формат, список цеглинок і як додати нову: [docs/skill-forge-format.md](../docs/skill-forge-format.md).

## Як відкрити
Скачай папку й відкрий `index.html`. Інтернет не потрібен.

## Перевірка
`node test/forge.test.js` (реєстр, вкладення, формат і міграція, імпорт сміттєвих даних, оцінка, приклади, випадковий скіл, прев'ю).
