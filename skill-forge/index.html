Що це

Конструктор здібностей для ігор. Скіл збирається з цеглинок чотирьох видів: доставка (як досягає цілей: снаряд, конус, зона, виклик…), модифікатор (пробиття, ланцюг, розкол, затримка…), ефект (шкода, лікування, контроль, ривок, посилення…) і тригер (при вбивстві, коли закінчиться… із вкладеними цеглинками).

Для чого

Щоб швидко придумати скіл і побачити, як він виглядає, що робить і чи не надто він сильний для своєї ціни. Готовий скіл виходить у JSON із версією формату, який легко прочитати в грі (Godot C#).

Як користуватися

  1. Почни з прикладу у блоці «Приклади» або натисни «Випадковий скіл».
  2. Додавай цеглинки зліва: вони стають у вибрану цеглинку, якщо туди можна. Параметри змінюй у картках посередині.
  3. Дивись прев’ю й оцінку справа: кнопка «Запустити» показує дію на п’яти манекенах.
  4. Збережи у верхній панелі: JSON, опис, друк або вузол для дерева скілів.
