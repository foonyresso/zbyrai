Що це

Генератор підземель із кімнат-тайлів. Кожна кімната лежить у своїй клітинці ґратки, двері двох сусідніх кімнат завжди стикуються коридором. Є відгалуження, петлі, глухі кути, таємні кімнати, пастки, істоти й здобич, а також кілька поверхів зі сходами. Усе від зерна: те саме зерно дає те саме підземелля.

Для чого

Для настільних і відеоігор: швидка карта для сесії, заготовка рівня, ідея для лабіринту. Типи підземель (каналізація, катакомби, шахта, склеп…) беруться з Атласу, тож розміри, небезпека й мешканці збігаються з підземеллями на карті світу.

Як користуватися

  1. Обери тип праворуч (або «Вільне»), кількість кімнат від 3 до 300 і поверхи.
  2. Натисни «Зарандомити» (Пробіл) або підкрути «Розгалуження», «Петлі», «Таємниці», «Пастки».
  3. Коліщатко мишки наближає, перетягування рухає карту, клік по кімнаті показує її вміст.
  4. Збережи кнопками угорі: PNG, JSON, посилання, друк.
