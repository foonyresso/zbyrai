# Симулятор підземель

Генератор підземель із кімнат-тайлів. Кожна кімната лежить у своїй клітинці ґратки 12×12 плиток; двері двох сусідніх кімнат стикуються коридором. Усе від зерна: те саме зерно й налаштування дають те саме підземелля.

- **Структура**: дерево кімнат (повзунок «Розгалуження»: довгі ходи чи багато відгалужень), «Петлі» (додаткові з'єднання колом), глухі кути, таємні кімнати з таємними дверима (лише на глухих кутах і петлях, тож видима частина лишається зв'язною), пастки, істоти й здобич.
- **Поверхи**: до 6, сходи вниз у найдальшій кімнаті збігаються зі сходами нагору наступного поверху. На останньому поверсі найдальша кімната — фінальна зала.
- **Розмір**: від 3 до 300 кімнат у сумі (300 генеруються за ~15 мс). Карта з зумом коліщатком, перетягуванням і дотиками; при малому масштабі малюється растром без деталей.
- **Типи з Атласу**: 29 типів із `medieval-world/dungeons/` (каналізація, катакомби, склеп, шахта, печери…). Вибір типу задає межі кімнат і поверхів, небезпеку, стиль (зали чи печери) і мешканців. На карті світу підземелля лише позначка з типом і розміром; цей інструмент будує їхню «середину» з тими самими межами. Перегенерувати дані типів: `node tools/build-dungeon-types.mjs`.
- **Вигляд**: теми карти (камінь, креслення, жар), шари (пастки, істоти, здобич, назви, таємні двері). Клік по кімнаті показує вміст.
- **Збереження й обмін** у верхній панелі: PNG поточного поверху, JSON (файл і буфер), посилання (`#s=…`), імпорт, друк усіх поверхів.
- **«Зарандомити»** (Пробіл): усе нове; замочок «Замкнути тип» лишає тип.

Формат JSON: `{v:1, seed, type, rooms, levels, style, branch, loops, secrets, traps, danger}` (версія 1). Невідомі поля ігноруються, значення обмежуються.

Не робиться (відкладено автором як складне): воксельне підземелля, повноцінне планування замків із кресленнями.

Стан у браузері: `dg_…`.

## Як відкрити

Скачай папку й відкрий **`index.html`**. Інтернет не потрібен.

## Перевірка

```sh
node dungeon-sim/test/dungeon.test.js
```

Файли: `dungeon-core.js` (генерація, без DOM), `dungeon-types.js` (типи, генерується), `dungeon-render.js` (canvas), `app.js` (інтерфейс), `style.css`, `theme.css`/`tool-chrome.js` (копії зі `shared/`).
