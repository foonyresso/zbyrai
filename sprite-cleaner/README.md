# Чистильник спрайтів: чистильник спрайт-листів і фону

Прибирає фон з будь-якого зображення: зі спрайт-листів (зокрема від ШІ) і зі звичайних фотографій. Редактор займає весь екран: ліворуч смуга інструментів, праворуч панель налаштувань, зверху файл, збереження й обмін.

1. **Кольори фону.** Не один колір, а список: піпеткою клікайте по небу, піску, морю, і кожен колір отримує власний допуск. Піксель прозорий, якщо він схожий на будь-який із кольорів. Кнопка «З країв» сама знаходить до 3 найпоширеніших кольорів по краях. «М'який край» робить плавний перехід, режим «З краю» не чіпає однаковий колір усередині предмета, «Скрізь» прибирає його всюди.
2. **Ручні правки** (поверх кольорів): «Паличка» стирає суміжну (або всю) область схожого кольору, Shift відновлює; «Ластик» і «Відновити» працюють пензлем; «Рамка» стирає або (Shift) відновлює прямокутник. Є скасування й повтор (Ctrl+Z, Ctrl+Y).
3. **Перегляд.** Масштаб колесом або pinch, рух пробілом чи інструментом «Рух», тло шашка/біле/чорне/рожеве/сіре, порівняння з оригіналом (утримуйте O), піксель і колір під курсором.
4. **Нарізка.** Автоматично (зв'язні області, зливання близьких частин, фільтр пилу) або сіткою N×M.
5. **Палітра.** Зменшення кількості кольорів (медіанний зріз) для піксель-арту.
6. **Збереження** (верхня панель): PNG, копія PNG у буфер, спрайти ZIP, атлас PNG + JSON (TexturePacker JSON Hash для Phaser, PixiJS), налаштування як JSON (копіювати, експорт, імпорт; також Ctrl+V із текстом JSON).

Гарячі клавіші: H, I, W, B, R, M (інструменти), [ і ] (розмір пензля), 0 (вмістити), 1 (100%), + і − (масштаб).

Усе рахується в браузері, налаштування зберігаються локально (`sc_…`). Зображення до 24 мегапікселів.

## Як відкрити

Скачай цю папку й відкрий **`index.html`** подвійним кліком. Встановлення й інтернет не потрібні.

## Перевірка

Потрібен лише Node: `node test/sprite.test.js` (кілька кольорів фону з допусками, flood/global, м'який край, пошук кольорів по краях, паличка, пензель, рамка, відновлення, пошук спрайтів, нарізка, палітра, упаковка атласу, CRC32 і структура ZIP).

**Інтерфейс:** зображення на весь екран; інструменти зліва, налаштування справа іконками («Фон», «Правки», «Нарізка», «Палітра», «Атлас») у висувній панелі; довідка згорнута за замовчуванням.
