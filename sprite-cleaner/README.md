# Sprite Sheet Cleaner: чистильник спрайт-листів

Бере спрайт-лист (наприклад, згенерований ШІ на однотонному фоні) і доводить його до стану, придатного для рушія. Продовжує Prompt Dice.

1. **Фон.** Колір фону береться по краях картинки автоматично, або піпеткою. Допуск ловить відтінки (шум JPEG), «м'який край» робить плавний перехід.
   Режим «лише зовнішній фон» не чіпає той самий колір усередині спрайта (очі, шви), «усі пікселі цього кольору» прибирає скрізь.
2. **Нарізка.** Автоматично: зв'язні області непрозорих пікселів (з параметром «зливати частини ближче ніж» для спрайтів з відірваними деталями й фільтром пилу),
   у порядку читання. Або сітка N×M з обрізанням порожніх країв.
3. **Палітра.** Зменшення кількості кольорів (медіанний зріз, без дізерінгу), палітра показується смужкою.
4. **Експорт.** Очищений лист PNG, усі спрайти окремими PNG у ZIP, атлас PNG + JSON у форматі JSON Hash (TexturePacker; його читають Phaser, PixiJS та ін.)
   з відступом і опцією «степені двійки».

Усе рахується в браузері, налаштування зберігаються локально (`sc_…`).

## Як відкрити

Скачай цю папку й відкрий **`index.html`** подвійним кліком. Встановлення й інтернет не потрібні.

## Перевірка

Потрібен лише Node: `node test/sprite.test.js` (фон, пошук спрайтів, нарізка, палітра, упаковка атласу, CRC32 і структура ZIP).
