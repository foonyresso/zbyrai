Що це, для чого, як користуватися

Що це. Редактор прибирає фон із зображення й робить його прозорим. Працює і зі спрайт-листами (в тому числі від ШІ), і зі звичайними фотографіями.

Для чого. Підготувати спрайти для гри, вирізати предмет чи людину з фото, нарізати лист на окремі спрайти й зібрати атлас PNG + JSON.

Як користуватися.

  1. Відкрийте картинку: кнопка «Відкрити…» зверху, перетягування у вікно або Ctrl+V. Або натисніть «Демо».
  2. Інструментом «Піпетка» клікайте по кольорах фону (небо, пісок, море): кожен колір потрапляє у список праворуч зі своїм допуском. Усе схоже на ці кольори стає прозорим (шашка).
  3. Що лишилося зайвим, доправте вручну: «Паличка» стирає суміжну область, «Ластик» і «Відновити» працюють пензлем, «Рамка» стирає прямокутник. Помилилися: Ctrl+Z.
  4. Колесо миші змінює масштаб, пробіл + тягнення (або інструмент «Рух») пересуває картинку. Утримуйте O, щоб порівняти з оригіналом.
  5. Зверху збережіть результат: PNG, копія в буфер, ZIP зі спрайтами, атлас або JSON налаштувань.

1 Кольори фону

Усе, що схоже на ці кольори, стає прозорим. Кожен колір має власний допуск: чим більший, тим ширший діапазон відтінків.

2 Ручні правки

Налаштування інструментів «Паличка», «Ластик», «Відновити». Працюють поверх кольорів фону.

3 Нарізка

Розділяє лист на окремі спрайти для ZIP і атласу.

4 Палітра

Зменшує кількість кольорів (стиль піксель-арту). Для фото краще вимкнути.

5 Параметри атласу

Як пакувати спрайти кнопкою «Атлас» зверху. Формат JSON Hash (TexturePacker) читають Phaser, PixiJS та інші рушії.
