# Планувальник виробничих ланцюжків: планувальник виробничих ланцюжків

Скільки машин і сировини потрібно, щоб виробляти X одиниць продукту за хвилину? Для Factorio-подібних ігор, колоній і міських симуляторів.

- **Рецепти**: час циклу, будівля, входи й виходи (кілька виходів = побічні продукти). Ресурс, якого ніхто не виробляє, автоматично стає сировиною.
- **Цілі**: кілька продуктів одразу; спільні проміжні ресурси рахуються разом.
- **Налаштування**: вибір способу виробництва, якщо ресурс має кілька рецептів; «брати ззовні» для будь-якого ресурсу; множники швидкості будівель.
- **Результат**: машини (точно й округлено вгору), циклів на хвилину, сировина й надлишок побічних продуктів, найвужче місце, схема потоків із товщиною за швидкістю.
- Цикли у виробництві виявляються з поясненням, що робити. Експорт: текст, CSV, JSON (і імпорт JSON).

У шапці зібрано все для збереження й обміну: «Показати приклад» (одним кліком), копіювати JSON, імпорт, експорт JSON, копіювати текст, CSV. Угорі сторінки є блок «Що це, для чого, як користуватися», а кожна кнопка й параметр має підказку при наведенні.

Три приклади в меню: середньовічне селище (хліб і мечі), завод механізмів, хімія з побічними продуктами. Стан зберігається в браузері (`pp_…`).

## Як відкрити

Скачай цю папку й відкрий **`index.html`** подвійним кліком. Встановлення й інтернет не потрібні.

## Перевірка

Потрібен лише Node: `node test/planner.test.js` (ланцюжок, швидкості, побічні продукти, альтернативні рецепти, цикли, збіжність потоків).
