# Генератор середньовічних міст

Генератор середньовічних міст і світу навколо них. Усе визначається seed: те саме число й ті самі параметри дають те саме місто.
Розмір від хутора до столиці, планування (радіальне, решітка, звивисте, витягнуте), біоми, річки з мостами, море з причалами,
шари (магія, ніч, райони, підземелля, рельєф), редактор споруд і власної стіни, нескінченний світ із селами та дорогами.

## Як відкрити

Скачай цю папку й відкрий **`index.html`** подвійним кліком. Встановлення й інтернет не потрібні.

Керування: перетягування рухає карту, колесо миші масштабує, подвійний клік по поселенню переходить до нього.
