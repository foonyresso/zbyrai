# Колаж фото

Додай фото, задай розмір полотна, і вони самі розкладуться. Полотно як у Photoshop: окремий вигляд із масштабом (колесо, −/＋, «Вмістити», 100%) і пересуванням (перетягування фону, Пробіл, середня кнопка); Shift+колесо над фото наближає кадр. Меню меню іконками зліва («Полотно», «Розкладка», «Фото»), рандом і додавання внизу.

- **Режими розкладки:** мозаїка (випадкові розрізи), рядки, стовпці (ширина комірки підлаштовується під пропорції фото), сітка, одне велике + решта.
- **Окреме фото:** клік вибирає; перетягування двигає рамку (з Alt або в режимі «Кадр» зсуває обрізання всередині рамки); колесо мишки наближає кадр; кутик рамки змінює розмір; у меню «Фото» є повзунки, поля розміру, «На місце», «Скинути кадр», видалення (Delete).
- Рандом («Розкласти інакше»), експорт у PNG, JSON з налаштуваннями (формат версія 2, див. `docs/data-versions.md`).

Логіка розкладки без DOM: `collage-core.js` (тест: `node photo-collage/test/collage.test.js`). Ключ localStorage: `pc_` (розмір, проміжок, колір, режим).
Відкрий `index.html` подвійним кліком; інтернет не потрібен. JSON зберігає налаштування й дані кадру, але не самі фото.
