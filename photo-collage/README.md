# Колаж фото

Проста версія: додай кілька фото, задай розмір полотна, і вони самі розкладуться (з легким обрізанням під комірки).
Є рандом розкладки («Розкласти інакше»), ручне пересування фото мишкою (подвійний клік повертає на місце) і експорт у PNG.
Логіка розкладки без DOM: `collage-core.js` (тест: `node photo-collage/test/collage.test.js`). Ключ localStorage: `pc_` (розмір, проміжок, колір).
Відкрий `index.html` подвійним кліком; інтернет не потрібен. JSON зберігає лише налаштування, не самі фото.
