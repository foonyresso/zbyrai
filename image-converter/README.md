# Конвертер зображень

Закидаєш пачку фото, обираєш формат, пропорції й розмір, забираєш усе одним ZIP. Усе в браузері, фото нікуди не вантажаться.

- **Формати:** WebP (рекомендовано 80), JPEG (82), PNG (без втрат), AVIF (55; лише якщо браузер вміє). Три готові рівні якості: «Мала вага», «Рекомендовано», «Максимум».
- **Пропорції:** оригінал, 1:1, 4:3, 3:2, 16:9, 21:9, 3:4, 2:3, 4:5, 9:16 або своя. Ширина й висота зв'язані: змінюєш одну, друга рахується за пропорцією. Для «Оригіналу» задається максимум довгої сторони.
- **Кадр:** на кожній мініатюрі видно, що потрапить у результат. Перетягни фото, щоб посунути кадр; колесо наближає; подвійний клік скидає. Є «Застосувати кадр до всіх».
- **Додатково:** ліміт ваги файлу (якість добирається автоматично), «не збільшувати малі фото», колір фону для JPEG, суфікс імені, показ економії місця, EXIF-поворот застосовується, метадані прибираються.
- **Обробка:** Web Worker-и (до 4 паралельно); якщо сторінку відкрито як `file://` і воркери заборонені, працює по черзі на головному потоці. ZIP без стиснення, збирається локально; понад ~1,5 ГБ ділиться на кілька архівів.
- JSON: налаштування й кадри за іменем файлу (версія 1, `docs/data-versions.md`). Ключ localStorage: `ic_`.

Тести: `node image-converter/test/convert.test.js`.
