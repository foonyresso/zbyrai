# Симуляція поселення

Живе піксельне містечко: 20 жителів зі своїми домами, професіями й потребами; сплять удома («zZZ» над дахом), працюють, розмовляють, обідають у таверні, відпочивають у парку; монстри біля воріт піднімають тривогу. Карта файлів: [docs/settlement-sim.md](../docs/settlement-sim.md).

Тести: `node settlement-sim/test/layout.test.js`, `node settlement-sim/test/mechanics.test.js`.
