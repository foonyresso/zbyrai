# Idea Mixer: змішувач ігрових ідей

Кубик, що складає ідею гри з семи слотів: **ядро, прогресія, світ, твіст, обмеження, тон, вигляд**. Варіанти взято з механік відомих ігор
(на картці видно, з яких саме). Принцип: не копіювати гру, а взяти механіку з однієї й доповнити механікою з іншої.

- **Змішати** (Пробіл) перекидає всі незамкнені слоти; 🔒 замикає слот, 🎲 перекидає лише його.
- **Пітч**: готовий Markdown (назва, список слотів, «Основа: ігри»), копіюється однією кнопкою: зручно вставити в розмову чи нотатки.
- **Вибране** (до 40 ідей) і **власні механіки**, які потрапляють у кубик нарівні з вбудованими. Усе зберігається в браузері (ключі `im_…`).

## Як відкрити

Скачай цю папку й відкрий **`index.html`** подвійним кліком. Встановлення й інтернет не потрібні.

## Перевірка

Потрібен лише Node: `node test/mixer.test.js` (пули, визначеність seed, замикання слотів, власні механіки, пітч).
