Що це

Дерево скілів, як в рольових іграх: ти вкладаєш очки у вузли, кожен вузол дає бонус або здібність і відкриває сусідів. Тут його можна намалювати, згенерувати та одразу «пограти».

Для чого

Щоб розробнику гри швидко придумати й перевірити систему прокачки: чи не надто легко добратися до сильного вузла, чи є цікавий вибір між гілками, чи вистачає очок. Готове дерево виходить у JSON.

Як користуватися

  1. Створи дерево праворуч: обери тип, постав кількість вузлів (хоч 500, хоч 5000) і натисни «Згенерувати».
  2. Грати: клік по вузлу вкладає очко, Shift+клік або правий клік повертає. Яскраві вузли доступні зараз.
  3. Редагувати: тягни вузли, подвійний клік по порожньому місцю додає новий, Shift+клік по іншому вузлу з’єднує.
  4. Збережи у верхній панелі: JSON, файл чи картинка PNG.

Кольори й форми

Колір = що дає вузол: зелений пасивний бонус, помаранчевий активна здібність, сіро-блакитний прохідний (лише з’єднує, безкоштовний), золотий початок. Форма = важливість: коло малий, ромб значний, шестикутник ключовий.

Приклади: «три класи» (тип «Класи»), довга лінія прокачки (тип «Ланцюг»), дерево технологій RTS (тип «Технології»).
