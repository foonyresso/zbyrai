Кубик промптів

Що це

Кубик для ШІ-промптів із манекеном людини: збирає випадкові, але продумані описи для генераторів зображень (Stable Diffusion, Flux, Gemini): персонажі, спрайт-листи, локації, піксель-арт.

Для чого

Щоб не вигадувати кожен промпт з нуля й при цьому керувати кожною деталлю: від стопи до волосся, від пози до фону. Кидай кубик, поки не сподобається, замикай вдале, правь решту руками.

Як користуватися

  1. Обери тип, модель, стиль і тематику у верхній панелі.
  2. Меню ліворуч: категорії (Персонаж, Волосся, Обличчя, Тіло, Одяг…) відкриваються в підгрупи; клік по підгрупі показує її параметри посередині. Пошук знаходить параметри й окремі варіанти («червоний», «роги», «окуляри»).
  3. Манекен: перемикач «Меню / Манекен» над меню. Клікни по нозі, руці, голові, очах… й отримаєш параметри саме цієї ділянки. «Цілі частини» вибирає одразу всю руку, ногу чи торс.
  4. Кинь кубик (Пробіл) для випадкового результату; 🔒 замикає вдале (у картці, підгрупі чи цілій категорії), 🎲 перекидає лише це, ∅ прибирає з промпта.
  5. Забери промпт праворуч (разом із негативним для SDXL). Зверху: пресети, історія кидків і налаштування (теги 18+, тексти промпта).
