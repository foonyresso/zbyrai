Що це

Кубик для ШІ-промптів: збирає випадкові, але продумані описи для генераторів зображень (Stable Diffusion, Flux, Gemini): персонажі, спрайт-листи, піксель-арт для ігор.

Для чого

Щоб не вигадувати кожен промпт з нуля. Кидай кубик, поки не сподобається, замикай вдалі частини й перекидай решту.

Як користуватися

  1. Обери тип, модель, стиль і тематику у блоці «Параметри».
  2. Натисни «Кинути кубик» (або Пробіл): справа зʼявиться готовий промпт, його можна правити руками.
  3. Замкни 🔒 те, що сподобалось, або перекинь один параметр 🎲.
  4. Збережи чи скопіюй кнопками угорі. Вкладки «Історія» і «Пресети» повертають попередні варіанти.

Параметри

Текст можна правити вручну. Будь-яка зміна параметрів чи кидок перезапише його. Пробіл — кинути кубик, Ctrl+Enter — копіювати.
⚠ SDXL погано робить «розбірку на частини» — спрайт-лист ракурсів вийде, але для чистих окремих частин краще Gemini або Flux.
