Що це

Кубик для ШІ-промптів із манекеном людини: збирає випадкові, але продумані описи для генераторів зображень (Stable Diffusion, Flux, Gemini): персонажі, спрайт-листи, локації, піксель-арт.

Для чого

Щоб не вигадувати кожен промпт з нуля й при цьому керувати кожною деталлю: від стопи до волосся, від пози до фону. Кидай кубик, поки не сподобається, замикай вдале, правь решту руками.

Як користуватися

  1. Обери тип, модель, стиль і тематику у смузі над робочою зоною.
  2. Клікни по манекену: нога, рука, голова, очі, волосся… Праворуч від нього зʼявляться варіанти цієї ділянки та поле для власного опису. «Цілі частини» вибирає одразу всю руку, ногу чи торс.
  3. Кинь кубик (Пробіл) для випадкового результату; 🔒 замикає вдале, 🎲 на картці перекидає лише його, ∅ прибирає з промпта.
  4. Забери промпт праворуч: копіювання, збереження, історія й пресети; обмін файлами в панелі вгорі.
