# Кубик промптів

Кубик для ШІ-промптів: випадкові, але продумані промпти для Stable Diffusion (теги у 4 групах), Flux і Gemini.
Типи: персонаж, спрайт-лист (ракурси й розібрані частини), локація, піксель-арт для 2D-ігор.
Режим **Flux** пише жива мова: для кожної групи параметрів (особа, волосся, очі, обличчя, тіло, одяг, поза, місце, світло, настрій) є одне шаблонне речення; якщо тегів для групи немає, шматок пропускається; змінюються лише потрібні слова; є умовні доповнення (світяться очі, кольорові пасма, «ліва/права» рука через присвійне слово тощо). Граматика: `flux-grammar.js`, словник тегів: `flux-words.js` (рядки `тег=фраза`; чого немає, те перетворюється загальним правилом). Тест: `node prompt-dice/test/flux.test.js`.
Параметри можна замикати чи вибирати вручну; є історія, пресети й налаштування шаблонів.

## Як відкрити

Скачай цю папку й відкрий **`index.html`** подвійним кліком. Встановлення й інтернет не потрібні.
Налаштування, історія та пресети зберігаються в браузері (ключі `pd2_…`).

Клавіші: **Пробіл** кидає кубик, **Ctrl+Enter** копіює промпт.
