# Кубик промптів

Кубик для ШІ-промптів: випадкові, але продумані промпти для Stable Diffusion (теги у 4 групах), Flux і Gemini.
Типи: персонаж, спрайт-лист (ракурси й розібрані частини), локація, піксель-арт для 2D-ігор.
Режим **Flux** пише жива мова: для кожної групи параметрів (особа, волосся, очі, обличчя, тіло, одяг, поза, місце, світло, настрій) є одне шаблонне речення; якщо тегів для групи немає, шматок пропускається; змінюються лише потрібні слова; є умовні доповнення (світяться очі, кольорові пасма, «ліва/права» рука через присвійне слово тощо). Граматика: `flux-grammar.js`, словник тегів: `flux-words.js` (рядки `тег=фраза`; чого немає, те перетворюється загальним правилом). Тести: `node prompt-dice/test/flux.test.js`, `node prompt-dice/test/mannequin.test.js`, `node prompt-dice/test/menu.test.js`.
**Меню.** Ліворуч перемикач «Меню / Манекен». Меню: 11 основних категорій (Персонаж, Волосся, Обличчя, Тіло, Одяг, Аксесуари й зброя, Поза й дія, Камера й кадр, Локація й фон, Світло й атмосфера, Ефекти й деталі) і, залежно від типу й моделі, 18+, Спрайт-лист, Запит до Gemini розкриваються в підгрупи; клік по підгрупі показує її параметри посередині. Пошук знаходить параметри й окремі варіанти (навіть за кольором). 🔒 замикає параметр, підгрупу чи цілу категорію, 🎲 перекидає лише їх, ∅ прибирає з промпта. Налаштування: розділи меню, компактний вигляд, одна відкрита категорія, розділ 18+ (за замовчуванням вимкнений). Дані меню: `menu-tree.js`.
Файли манекена: `mk-shapes.js` (геометрія, ділянки, групи), `mk-data-*.js` (категорії), `mk-slots.js` (слоти → типи промптів), `ui-mannequin.js`. Як додати категорію: рядок у `mk-data-extra.js` (id, ділянка, назва, режим, `Група:: підпис=промпт; …`).
**Манекен**: векторна фігура (тіло й обличчя) поділена на 30+ клікабельних ділянок: стопи, пальці ніг, щиколотки, гомілки, коліна, стегна, таз, талія, живіт, груди, плечі, плече, лікоть, передпліччя, зап'ястя, кисть, пальці, шия, щелепа, підборіддя, рот, ніс, щоки, очі, брови, лоб, чубчик, вуха, волосся, головний убір. Клік відкриває параметри ділянки (готові варіанти + поле «Свій опис»). Перемикач «Цілі частини» вибирає всю руку, ногу, торс чи голову. Є 100+ категорій: деталі тіла, одяг, прикраси, розширені пози, фони й об'єктиви. Нові параметри вимкнені, доки їх не вибрано чи не кинуто кубиком на ділянці (🎲 «Випадково»). Ідеї взято зі старого плагіна Stable Diffusion «Конструктор персонажа».
**Назви й групи.** У вибірі все українською (словник `ua-tags.js`, `ua-body.js`, `ua-outfit.js`, `ua-scene.js`, `ua-pixel.js`: рядки `тег=назва`), у промпті англійські теги. Старі параметри поділено на групи (`mk-spec.js`, злиття й усунення дублікатів у `mk-merge.js`): «одне з групи» там, де варіанти виключають один одного. Стать задається лише параметром «Стать». Мова поки лише українська; адаптивна мова (за мовою браузера) запланована, див. `docs/edits/04-prompt-dice.md`.
**Кольори й раси.** Волосся, очі, нігті, шкіра, крила, роги, хвости, одяг та інше мають квадратики кольорів і вибір довільного кольору (`colors.js`). Картка «Расові особливості» показує окреме меню вибраної раси (`race-data.js`).
Параметри можна замикати чи вибирати вручну; історія, пресети й налаштування у верхній панелі.

## Як відкрити

Скачай цю папку й відкрий **`index.html`** подвійним кліком. Встановлення й інтернет не потрібні.
Налаштування, історія та пресети зберігаються в браузері (ключі `pd2_…`).

Клавіші: **Пробіл** кидає кубик, **Ctrl+Enter** копіює промпт.
