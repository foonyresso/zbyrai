Генератор персонажів

Що це

Генератор листка персонажа для D&D 5e (правила SRD 5.1): раса, клас, рівень 1-20, характеристики, навички, HP, КБ, закляття, риси, спорядження й особистість.

Для чого

Щоб швидко отримати готового персонажа для гри: НПС, запасного героя, пригоду на один вечір. Усе, що не зафіксуєш, обирається випадково.

Як користуватися

  1. Натисни «Зарандомити» (або Пробіл): з’явиться новий листок.
  2. Зафіксуй потрібне ліворуч: расу, клас, рівень, навички. Решту рандом змінюватиме.
  3. «Закріпити поточне» залишає расу й клас теперішнього персонажа, а решту можна перекидати.
  4. Збережи чи надрукуй кнопками угорі: JSON, друк, імпорт.
