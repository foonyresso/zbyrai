# Відео редактор і конвертер

Відкриваєш відео чи аудіо, ріжеш на частини, видаляєш зайве, кадруєш, міняєш швидкість і гучність, забираєш у MP4, WebM, GIF або MP3. Усе в браузері на ffmpeg.wasm, файл нікуди не вантажиться.

- **Таймлайн:** частини з кадрами-мініатюрами. Клік виділяє частину, протяг виділяє будь-який діапазон (краї посуваються), лінійка зверху переміщує курсор, колесо гортає, Ctrl+колесо масштабує.
- **Правки:** розрізати (S), видалити виділене (Delete, решта зсувається), обрізати початок/кінець до курсора, лишити виділене, скасувати/повторити (Ctrl+Z, Ctrl+Shift+Z).
- **Частина:** швидкість ×0,1…×8 (звук розтягується зі збереженням тону) і гучність 0…200% для виділеного.
- **Кадр:** пропорції 1:1, 4:3, 3:2, 16:9, 21:9, 3:4, 2:3, 4:5, 9:16, своя або довільно руками; рамка на відео рухається й міняє розмір, числа X/Y/ширина/висота.
- **Звук:** загальна гучність 0…200%, «прибрати звук».
- **Експорт:** MP4 (H.264+AAC), WebM (VP9+Opus), GIF (палітра, 1–30 к/с), MP3 (128/192/320). Якість «мала вага / рекомендовано / максимум», розмір за висотою (4K…240p), своя ширина. Для файлів, які браузер не грає (MKV, AVI, HEVC…), робиться легка копія для перегляду, а експорт іде з оригіналу.
- Рушій ffmpeg (≈32 МБ) вантажиться з CDN при першому експорті чи незвичному файлі. Працює зі сторінки сайту (http/https), не з `file://`.
- Ключ localStorage: `ve_opt` (налаштування експорту), `ve_panel` (відкрите меню).

Файли, джерела й ліцензії: [docs/video-editor.md](../docs/video-editor.md), [vendor/README.md](vendor/README.md). Тести: `node video-editor/test/ve.test.js`.
