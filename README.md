# Zbyrai

Збірка безкоштовних браузерних інструментів. Без реєстрації, без встановлення, без інтернету після завантаження:
відкрив сторінку й працюєш. Усе рахується у твоєму браузері, нічого не надсилається на сервер.
Єдиний виняток: кнопка «Випадкове» в Конструктор візерунків завантажує випадкове фото з picsum.photos або Вікісховища (ваші дані при цьому не надсилаються).

**Сайт:** https://zbyrai.pages.dev/

## Кожен інструмент можна скачати окремо

Кожен інструмент лежить у власній папці й **повністю самодостатній**: жодних посилань на файли за межами папки,
жодних CDN, шрифтів чи скриптів з інтернету. Скачай папку, відкрий `index.html` подвійним кліком, і все працює.
Посилання «назад на головну» показується лише тоді, коли інструмент відкрито в складі сайту.
Єдині абсолютні адреси на сторінках інструментів стоять у метаданих (`canonical`, `og:url`) і на роботу офлайн не впливають.

## Структура

Детальна карта репозиторію (що де лежить, як додати інструмент, правила файлів, великі файли): **[docs/NAVIGATION.md](docs/NAVIGATION.md)**.

```
index.html          головна сторінка (хаб)
assets/             стилі й скрипт лише для головної
shared/theme.css    єдина дизайн-система «Обсидіан і золото» (джерело)
tools/sync-theme.mjs копіює shared/theme.css у theme.css кожного інструмента
prompt-dice/        інструмент
medieval-world/     «Проект Атлас»: інструмент; worlds/continent/ — тип світу «Материк» (core/, data/, render/, ui/, test/)
pattern-maker/      інструмент (+ test/ з тестами математики)
loot-forge/         інструмент (+ test/)
skill-tree/         інструмент (+ test/)
idea-mixer/         інструмент (+ test/)
character-roller/   інструмент (+ test/)
tessera/            інструмент (+ test/)
taste/              закрита довідка про ігрові смаки: не в меню й не на головній, відкривається лише за прямим посиланням
robots.txt          правила для пошукових систем + адреса sitemap
sitemap.xml         сторінки сайту для пошуковиків
```

## Для розробки

Збірки немає: це чиста статика (HTML, CSS, JS). Для Cloudflare Pages достатньо вказати корінь репозиторію
як каталог публікації й залишити команду збірки порожньою.

```sh
python -m http.server 8000        # локальний сервер, далі http://localhost:8000/
node tools/sync-theme.mjs         # після змін у shared/theme.css оновити копії в інструментах
node pattern-maker/test/fold.test.js   # тести математики Конструктор візерунків (потрібен лише Node)
node pattern-maker/test/fx.test.js     # тести ефектів Конструктор візерунків
node loot-forge/test/loot.test.js      # тести Кузня луту
node loot-forge/test/gdd.test.js       # тести розширеного шару
node planet-forge/test/planet.test.js      # тести Кузня планет
node voxel-lab/test/voxel.test.js      # тести Воксельна лабораторія
node colonist-foundry/test/colonist.test.js      # тести Симуляція колонії
node production-planner/test/planner.test.js      # тести Планувальник виробничих ланцюжків
node balance-curves/test/curves.test.js      # тести Криві балансу й хвилі
node sprite-cleaner/test/sprite.test.js      # тести Чистильник спрайтів
node skill-tree/test/tree.test.js      # тести Лабораторія дерев скілів
node idea-mixer/test/mixer.test.js     # тести Змішувач ідей
node character-roller/test/char.test.js      # тести Генератор персонажів
node tessera/test/tessera.test.js      # тести Мозаїка
node medieval-world/worlds/continent/test/run-all.js  # тести світу «Материк» (ієрархія, дороги, монстри, море, експорт)
node tools/build-atlas-registry.mjs         # оновити реєстр світів і біомів Атласу після додавання файлу
node tools/atlas-registry.test.js      # перевірка реєстру світів і біомів
node tools/ui-rules.test.js            # перевірка єдиних правил інтерфейсу (довідка, верхня панель, підказки)
```

Єдині правила інтерфейсу кожного інструмента: 1) усе, що зберігає й передає (копіювати, імпорт, експорт, завантажити, поділитися, друк), стоїть у верхній панелі `header.top > .top-actions`, а редагування й рандом лишаються в робочій зоні; 2) на початку згорнута довідка `<details class="how">` «Що це, для чого, як користуватися» (стилі в `shared/theme.css`); 3) підказка `title` для кожної кнопки й параметра; 4) увесь інтерфейс українською; 5) спільна тема й заголовки. `tools/ui-rules.test.js` перевіряє це для інструментів, які вже переведені.

Новий інструмент: створи папку з `index.html`, підключи власну копію `theme.css` (її створить `sync-theme.mjs`),
додай картку в `index.html` і не використовуй шляхи за межами папки інструмента.
Якщо інструмент зберігає щось у `localStorage`, дай ключам власний префікс (Кубик промптів: `pd2_`, Конструктор візерунків: `pm_`, Кузня луту: `lf_`, Лабораторія дерев скілів: `st_`, Змішувач ідей: `im_`, Симуляція колонії: `cf_`, Кузня планет: `pf_`, Воксельна лабораторія: `vx_`, Чистильник спрайтів: `sc_`, Генератор персонажів: `cr_`).
Кожен інструмент має власний акцент: колір у `:root` свого `style.css` (`--accent`) і клас `.c-…` у `assets/hub.css` для картки на головній.

Адреса сайту (`https://zbyrai.pages.dev`) стоїть у `canonical` та `og:url` кожної сторінки, у `sitemap.xml` і `robots.txt`.
Якщо домен зміниться, знайди всі входження командою `grep -rn zbyrai.pages.dev .` і онови разом.

`taste/` (довідка про ігрові смаки) теж отримує `theme.css` від `sync-theme.mjs`, але це не інструмент:
у `sitemap.xml` її немає, у `index.html` вона не згадується, а сама сторінка має `noindex`.
Нову гру додають одним записом у `taste/data.js`.
