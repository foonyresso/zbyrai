# Карта королівств

Фентезійна карта світу з одного зерна. Орієнтир вигляду: Azgaar Fantasy Map Generator, але світ більш фентезійний, а міста, дороги й лігва видно одразу на карті, а не в окремому віконці. **Це зразок механіки для гри на Godot C#**: файл у грі не використовується, переноситься механіка (див. [перенесення в C#](../docs/realm-map/csharp-port.md)).

## Як відкрити

Скачай цю папку й відкрий **`index.html`** подвійним кліком. Встановлення й інтернет не потрібні.

## Що вміє

- **Провінції → регіони → міста**: провінція як країна, регіон як область, кожен регіон належить до свого міста, столиця має найбільший регіон.
- **Чотири типи доріг**: великі (до центрів регіонів), середні (до менших міст, занепалих і захоплених монстрами), малі (до сіл, шахт, озер, гір, руїн, пам'ятників), стежки (до дрібних місць, таборів, лігв і босів).
- **Морські шляхи** між портами, на 2–4 км від берега, повз глибини з лігвами.
- **Монстри й боси** гір, лісів і морів: повні списки в [довіднику](../docs/realm-map/README.md).
- **Планувальник подорожі**, карта небезпеки, стани поселень (занепале, зруйноване, покинуте, захоплене монстрами), назви за культурами.
- Збереження: посилання, JSON параметрів, повний експорт світу, CSV міст, PNG, друк.

Керування: перетягування рухає карту, колесо миші масштабує, клік по об'єкту відкриває картку, подвійний клік наближає.

## Де що лежить

```
index.html, style.css, app.js     сторінка, стилі, точка входу інтерфейсу
core/    генерація без DOM (rng, noise, grid, terrain, climate, rivers, politics, settlements, pois, lairs, router, roads, searoutes, features, planner, serialize, ...)
data/    біоми, типи місць, назви, бестіарій гір/лісів/морів, шаблони зачіпок
render/  малювання на canvas: шари, значки, підписи, сцена
ui/      панелі (світ, шари, подорож, довідник), картка об'єкта, збереження й обмін
test/    тести: node realm-map/test/run-all.js
```

Документація за темами: [docs/realm-map/](../docs/realm-map/README.md).
