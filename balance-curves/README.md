# Криві балансу й хвилі: криві балансу й хвилі

Дві вкладки.

**Криві.** Скільки HP має ворог на 30-му рівні, скільки шкоди завдає гравець, скільки XP треба до наступного? Креслить кілька кривих на одному графіку
(лінійна, степенева, експоненційна, S-крива, логарифмічна), показує значення, накопичений підсумок чи приріст за крок у %, лог. шкалу.
«Підібрати під точки»: задаєте бажані значення на двох рівнях, параметри лінійної, степеневої чи експоненційної кривої розраховуються.
«Співвідношення двох кривих» (наприклад, шкода ÷ HP) показує, на яких рівнях баланс 1:1 і де він ламається. Типи: лінійна, степенева, експоненційна, S-крива, логарифмічна, сходинки, квадратична, корінь. Експорт: CSV, JSON, готова формула JS / Python / C#.

**Хвилі.** Кожна хвиля має бюджет складності з кривої; його витрачають на ворогів за вартістю (типи відкриваються з певної хвилі, мають вагу вибору).
Кожні N хвиль з'являється бос (частка бюджету на найдорожчий доступний тип). Зерно робить результат відтворюваним. Графік складу, таблиця, експорт CSV/JSON.

**Власні формули.** Тип кривої «Власна формула»: пишете вираз із змінними `x` (рівень, крок, хвиля, відстань), `a`, `b`, `p`, посиланнями на інші криві `c1…c20`, функціями (`min`, `max`, `floor`, `clamp`, `mix`, `if`…) і умовами `умова ? тоді : інакше`. Розбір безпечний (власний парсер, без `eval`), помилку видно під полем. «З бібліотеки формул»: ~20 готових (кожні N рівнів ×K, досвід MMORPG, ціни клікера, сила ворога за відстанню від центру карти, шанс дропу від різниці рівнів, бос кожні N хвиль, суми й відношення кривих). Власна формула годиться і для бюджету хвилі; окремо є «Зростання HP ворогів із хвилею». Код для гри (JS, Python, C#) теж працює з власними формулами.

Налаштування зберігаються в браузері (`bc_…`).

## Як відкрити

Скачай цю папку й відкрий **`index.html`** подвійним кліком. Встановлення й інтернет не потрібні.

## Перевірка

Потрібен лише Node: `node test/curves.test.js` (значення кривих, підбір за точками, перетини, бюджет хвиль, визначеність зерна, експорт), `node test/formula.test.js` (розбір і обчислення власних формул, код JS/Python/C#, бібліотека).

## Інтерфейс

Уся українською: «Криві балансу й хвилі». Угорі сторінки є блок «Що це, для чого, як користуватися»; кожна кнопка й параметр має підказку при наведенні. У шапці зібрано збереження й обмін: копіювати код кривої (JS, Python, C#), копіювати JSON, імпорт, експорт JSON, таблиця CSV і JSON поточної вкладки. Редагування й «Інше зерно» лишаються в робочій зоні. Графік займає весь екран; криві, співвідношення, таблиця (і бюджет, ХП, типи, склад хвиль) відкриваються іконками збоку, діапазон і вигляд — у нижній панелі.
