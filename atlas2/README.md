# Атлас 2.0

Що тут: новий генератор світу з нуля (не пов'язаний зі старим Атласом `medieval-world/`, той схований з хабу й відкривається за прямим посиланням). Дизайн: [docs/atlas2/DESIGN.md](../docs/atlas2/DESIGN.md). Відкрити: `index.html` (працює офлайн, подвійним кліком).

Порядок генерації (усе від зерна): ландшафт → річки й озера за правилами стоку → біоми → суходоли → столиці й провінції → регіони → поселення → дороги → морські шляхи.

| Папка | Що |
|---|---|
| `core/` | Логіка без DOM, по файлу на етап: `terrain`, `hydrology`, `climate`, `settle` (придатність), `grow` (ріст міток), `politics`, `settlements`, `roads`, `searoutes`, `serialize`, `index.js` (завантажувач для Node) |
| `render/` | Малювання: `contours` (плавні межі), `raster` (рельєф), `draw` (шари), `places` (дороги, міста, підписи) |
| `ui/app.js` | Інтерфейс: параметри, масштаб, збереження/імпорт/посилання/PNG |
| `core/landmarks.js` | Місця за великими містами (старі споруди, пам'ятники, краєвиди, технології) на відстані 1–5 км і стежки від них до мережі доріг; `render/landmarks.js` малює значки |
| `core/town*.js`, `core/city*.js` | Детальне місто на карті (проявляється з наближенням замість значка; дороги міста = дороги карти, берег і річки з тих самих контурів): `townenv` (вода, річки, дороги), `townstreets` (вулиці, провулки, A*-маршрути в обхід цвинтарів і води), `townroads` (чистка мережі: згладжування, без шпильок, вузли на перетинах, T-стики, злиті кінці), `town` (райони, площі, парки, споруди, міська стіна різної форми й матеріалу за рангом (у малих поселень щільно охоплює забудову, цвинтарі лишаються за муром), порт, руїни й окупація), `townfields` (поля тісними групами біля доріг за брамами: ділянка ділиться на охайні багатокутники 4–6 сторін різних розмірів і культур — оранка, сад, виноградник, луг; штрихи вздовж довгої сторони, живопліт; проміжки заповнюють гаї), `townkeep` (мур замку: кільце з баштами й брамами навколо замку, двір без звичайної забудови), `townquery` (пошук і тексти подробиць), `citydata`/`citytext` (типи споруд, райони, назви). Малювання й маска води: `render/town.js`, `render/townmask.js`; черга побудови, наведення, вікно подробиць, збереження: `ui/town.js`, `town.css` |
| `core/dungeon*.js` | Підземелля під містами: `dungeondata` (види, монстри, пастки, скарби, кімнати), `dungeon` (генератор карти від зерна: кімнати різних форм і розмірів, коридори, двері, секретні ходи, сходи між поверхами, монстри, пастки, скарби; `Dungeon.generate(spec)`), `dungeonplace` (розміщення під містом: вхід у споруді, відбиток у плані й смуга глибини; на одній глибині не перетинаються, великі багатоповерхові глибше за звичайні, ходи між підземеллями, часом секретні). Малювання: `render/dungeon.js`; інтерфейс (позначки входів на карті міста, екран підземелля, картки, збереження): `ui/dungeon.js`, `dungeon.css`. Зовнішній вхід (напр. склеп на цвинтарі): `A.DungeonUI.openById(id)` для підземелля з `DungeonPlace`, або `Dungeon.generate({id, seed, kind, size, level})` |
| `test/` | `node atlas2/test/run-all.js` |

Формати: параметри `atlas2-params` версії 1, повний світ `atlas2-world` версії 1 (див. [docs/data-versions.md](../docs/data-versions.md)).
